## 1. 范围（R1–R3 核心 + R4 扩展待拍板）

### R1 推荐页信息层重排

- **目标**：
  1. 全中文；
  2. 条目行：标题 / 状态徽标 / 类型分列（修"risepending"类粘连）；
  3. 详情区改人类可读摘要（score / confidence / 建议动作），`ID / RUN / REASON / EVIDENCE / PAYLOAD` 原始字段收进「原始数据（折叠）」；
  4. 时间戳格式化（本地时区、不做毫秒倾泻）；
  5. 按钮与提示中文（采纳 / 驳回 / 刷新条目；采纳后动作说明）。
- **交付物**：页面改造 + 文案替换清单（旧→新逐条）+ 前后截图。
- **验收**：截图对照；受影响源码目标英文串零残留（检索断言，白名单＝代码注释与标识符）；四态中受影响态。
- **工作量**：M

### R2 图页载入交互与空态

- **目标**：
  1. 载入策略按 §5-2 裁决落地——默认方案：**进入即自动加载默认视图**（当前筛选参数全 optional，无需先填）；`Load graph` 降级为筛选提交动作；
  2. 空态：无数据时引导（积累型口吻："你的素材网络还没成形——先去圈记几个词，它会长出来"），而非空白；
  3. 中文文案；
  4. §6-3 节点标签重叠一并评估（可低成本修则修，否则维持记录并在卡内声明）。
- **交付物**：页面改造 + 前后截图。
- **验收**：首屏截图（进入即有态）+ 空态截图 + 明暗双主题。
- **红线提示**：图读取为只读面，自动加载不触 L3 任何红线；不改后端、不加端点。
- **工作量**：M

### R3 工具页与读面页中文化（文案层）

- **目标**：受影响页的英文工程文案全量中文——导入 / 手动编辑 / 提议审查 / 词空间 / 语境条目 / 关联图 / 推荐 的表单标签、区块标题、按钮、空态、说明文字；空态口径与 baseline §4 文案总原则同源（积累型、中文、不催促）。
- **交付物**：替换清单（旧→新逐条核销）+ 每页至少 1 张前后截图。
- **验收**：检索断言——目标英文串（`Raw Import` / `Proposal Review` / `Load graph` / `Load word space` / `Generate recommendations` / `RECOMMENDATION QUEUE` / `GRAPH READ SURFACE` / `WORD SPACE` 等，执行时定稿白名单）在 `src/frontend/` 零命中；截图对照。
- **工作量**：S–M

### R4（扩展，待拍板）读面三页用户向信息结构重写

- **目标**：G-P1-3 完整版——词空间 / 语境 / 图从"表单＋Load＋空白"的检查器形态，重写为用户向信息结构：入口带参（从词卡 / 阅读视图 / 书架一跳直达）、信息层级（标题区 / 主内容 / 次级证据）、空态引导、四态完整。
- **工作量**：L（建议独立一轮执行）
- **说明**：此项系审计报告 §1 点名的"超 scope 残留（完整体验化）"，本卡将其显式立项为可拍板项，**未经拍板不纳入执行**。
