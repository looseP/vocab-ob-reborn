## 2. P0 级 Gap（必修）

### G-P0-1 圈记高亮完全不可见（+ 深链闪高亮失效）
- **证据**：`02b-reading-text-clip.png`（inside/enduring 无任何背景色）、`19-deeplink-focus.png`（`?contextId=` 落地后无闪高亮）、`20/25`（同）
- **根因**：`--color-accent-soft` 在全仓库**无定义**（`src/frontend` 全部 css/ts/tsx 检索为 0 条定义），但被阅读高亮 `mark`、闪高亮动画 `l3-focus-pulse`、书架"2 语境"徽章、面板计数徽章等大量引用 → 背景色静默失效。
- **基线条目**：§1 E3「痕迹被显形」（"高亮的不是词典，是你的踪迹"）；§5 已知缺口预警。
- **修法**：在 `:root` 与 `[data-theme="dark"]` 补 `--color-accent-soft` 定义（浅色：淡绿底如 `rgba(15, 111, 98, 0.12)`；深色：`rgba(62, 201, 180, 0.16)` 级别），在真实页面验证 mark / 闪高亮 / 徽章三处恢复。
- **工作量**：S ｜ **批次：B3**（属"阅读与圈记对齐"的直接修复）

### G-P0-2 圈记偏移映射 off-by-N（badge 文本节点污染）
- **证据**：`20-capture-strip.png` —— 页面实测：划选 `enduring` 后浮层显示「已选中：**nduring**」「词库中还没有「nduring」」（实测丢失首字母 = +1 偏移；每多一个前置标号再多 +1）。
- **根因**：`L3ReadingView.computeGlobalOffsets` 用 `TreeWalker(SHOW_TEXT)` 累计容器内全部文本节点长度，**句尾标号按钮里的数字文本（"1"/"2"…）被计入**，而它们不属于正文 `content_text` → 选区在标号之后时偏移按前面标号数递增。
- **影响**：① 用户圈记写入的 anchor/record 偏移错位；② 库内词被误判为"不在库"→ 引导用户创建**错误的 stub 词**（"nduring" 会进库，脏数据）；③ 高亮位置与圈记位置漂移。
- **基线条目**：§8 自查 4（FR-3 圈记绑定核查项）。
- **修法**：TreeWalker filter 跳过 `[data-context-badge]` 子树内的文本节点（或仅遍历 `[data-reading-text]` 内非标号文本）；补纯函数级测试（构造含标号的 DOM；沿用"绕过 jsdom Range 限制直测纯函数"的既有先例）。
- **工作量**：S–M ｜ **批次：B3**

## 3. P1 级 Gap

### G-P1-1 空间首页 = 占位符（B1 主体）
- **证据**：`03-home-placeholder.png`（"挂载状态页"+ Cache reason `phase_4c_local_state_no_global_cache` 工程术语裸露）
- **基线条目**：§1 E1/E2、§2（首页六区块全部缺失）、§4（素材宇宙四态全部缺失）。
- **修法**：B1 全量交付（素材宇宙：生长计数/最近导入/最近圈记；空态积累型；IA-1/IA-2 落地）。
- **工作量**：L ｜ **批次：B1**

### G-P1-2 暗色模式对比度（active 导航 / accent 底按钮）
- **证据**：`21/22/23`——侧栏 active 项亮绿底 + 白字（≈1.7:1，几不可读；`styles.css:815` fallback `#ffffff`）；导入按钮同类。
- **根因**：`--color-accent-contrast` 无定义 + fallback 策略在暗色反转场景不成立。
- **修法**：补 `--color-accent-contrast` 双套定义（light `#ffffff` / dark 取深色如 `#0f1c1a`），统一全站 accent 底文字。
- **工作量**：S ｜ **批次：B4**

### G-P1-3 读面三页 = 工程检查器（英文 + 裸 JSON）
- **证据**：`04-word-space.png`、`05-context.png`、`16-graph-loaded.png`、`17-word-space-loaded.png`、`18-context-loaded.png`（"inspect contexts, occurrences, links" 全套 debug dump；英文工程文案；`{}`/UUID/时间戳直接渲染）
- **基线条目**：§2 页面清单（词空间/图="视角"应有体验形态）；梳理文档 L528 点名批评。
- **修法**：完整体验化（中文化 + 用户向信息结构 + 空态）= L（**超本次 scope**，列残留）；本次 B4 只做低成本统一：区块卡片化、标题层级、间距、英文工程文案 → 中文、裸 JSON 收进"原始数据（折叠）"。
- **工作量**：L（完整）/ M（B4 缓解）｜ **批次：B4 缓解 + §6 残留**

### G-P1-4 推荐页原始 JSON / 时间戳 / 按钮粘连

- **工作量**：M ｜ **批次：B4 缓解**

### G-P1-5 批量导入 / 手动编辑表单布局散架
- **证据**：`10-import.png`（label 与控件挤压、占位文字重叠）、`11-manual.png`（全页表单成散沙、大量死白）

- **修法**：移动端（<768px）导航改为横向 chips 或收进折叠；桌面不变。

3. **图页节点标签重叠**（`16`）：两个来源节点标签"The Quiet Rise …"互相挤压、中间节点无可见标签——可视化布局的打磨问题，列 B2 之外的后续观察（B2 形态已预选"生长计数趋势"，不依赖图页改造）。
