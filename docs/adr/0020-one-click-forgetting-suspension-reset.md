# ADR-0020: 一键遗忘——非破坏性挂起重置 + 锚点词保留

- **Status**: Accepted
- **Date**: 2026-09-11
- **References**: ADR-0002（双轨 FSRS）、ADR-0004 §6（红线）、ADR-0018（seed/merge 语义区分）、CONTEXT.md（一键遗忘 / 锚点词）
- **上游**: 2026-09-11 增量认知设计拷问会话（第五轮）

## Context

搁置复习一段时间后回归的用户，面对积压的 due 队列会"无从下手"，由此产生"删除词书 / 重置进度"的破坏性冲动。需要的是**非破坏性软着陆**：给用户几个能立刻行动的锚点，快速恢复行动力。

保留标准（源性词 / 简易词 / 可派生 / 可关联 / 历史确认可保留）中的"可派生 / 可关联"依赖词网络，但同义 / 反义 / 派生关系**目前未纳入网络构建**——全量等图谱会无限期阻塞这个救场功能。

## Decision

1. **遗忘 = 挂起（suspension）**：一键遗忘把词书内非锚点词的进度行置为 `state = suspended`（枚举已存在，0 迁移）。**不是**删除、**不是** stability 重置、**不是** due 推迟。历史数据零改动，操作完全可逆（一键恢复）。
2. **作用域按书**：与进度模型（`(user, word, wordbook)`）一致；搁置场景几乎都绑定一本具体的书，全局重置会打乱其他正常推进的书。
3. **锚点词保留集的三段分工**：确定性算法出候选（FSRS 字段：stability / retrievability / 近期评分 + 现有词根 / morphology / 语义链关系）→ agent 做"模拟遗忘"叙事解读（把历史 review 讲成人话，给出保留理由）→ **用户确认**。agent 只叙事，不决策。
4. **弱关联版起步**：第一版只用现有字段与关系；**词网络图谱（同义 / 反义 / 派生）并行单独立项**，不作为本功能的前置。

## Tradeoffs

- **挂起 vs stability 重置**：重置会污染 FSRS 参数拟合所依赖的复习历史——用户攒的数据是自己的资产，不可逆地破坏它违背"非破坏性"的初衷。
- **挂起 vs due 推迟**：推迟后队列依然臃肿，"无从下手"的根因（认知负荷）没有解除；挂起让队列立刻变轻。
- **弱关联版 vs 等词网络**：锚点质量会随图谱上线提升，但第一版靠 FSRS 数据 + 词根族已足够给出"几个能快速恢复行动力的锚点"；救场功能不该被图谱工程阻塞。
- **按书 vs 全局**：全局重置把其他书的学习节奏一起打乱，弊大于利。

## Consequences

- ✅ 搁置回归者有软着陆路径，"删除词书 / 重置进度"的破坏性冲动被导流；操作完全可逆，心理门槛低。
- ✅ FSRS 拟合数据零污染；`suspended` 复用既有枚举与 RLS，0 迁移。
- ⚠️ 批量挂起/恢复是用户可见的批量操作，需要防误触的确认流（锚点清单预览 + 数量提示）。
- ⚠️ 词网络图谱立项上线后，锚点算法应回看升级（关联维度从"词根族"扩展到同义/反义/派生）。
- ⚠️ 锚点叙事由 agent 生成时，沿用既有红线：agent 产出仅作展示与建议，任何写入仍走既有通道。
