# ADR-0018: 用户主动提前升级（豁免 ADR-0002 晋升门槛）+ 一次性种子继承

- **Status**: Accepted
- **Date**: 2026-09-11
- **Amends**: ADR-0002 §晋升条件（仅新增"用户主动提前升级"豁免路径，自动晋升路径不变）
- **References**: ADR-0002（S≥21d、≥5 次、last good/easy）、ADR-0004 §6、ADR-0017（方向变体）、CONTEXT.md（升级标记 / 升级建议 / Seed）
- **上游**: 2026-09-11 增量认知设计拷问会话

## Context

换书重学场景：词在新书从 L1 重新起步，但它在历史书中可能早已掌握。ADR-0002 的晋升门（stability ≥ 21d、≥5 次复习、last good/easy）保护 L2 轨质量，但对"历史书中已掌握、当前书刚起步"的重叠词形成误伤——完整周期对这类词是纯开销。

用户的增量认知哲学：**升级不是自动化动作**。"升级标记 → 和 agent 交互校准内容 → 自我选择"本身就是一个独立于复习卡模式的学习过程，不需要全量自动化，只需要优化升级的使用逻辑和体验。

## Decision

1. **升级标记（work order）**：`(user, word, wordbook, direction, status: 标记中|升级中|已完成|已取消)`，配"待升级清单"视图。新书**首学/首复习后**，用户可将词标记提前升级入 L2——**豁免稳定性/次数门**（仅限该用户显式路径；ADR-0002 的自动晋升路径与门槛不变）。
2. **升级建议（纯函数、三档：强烈推荐升级 / 推荐升级 / 需要沉淀）**：输入为当前书 L1 `recent_ratings` + 他书 L2 `state/retrievability/l2_production_status`；**仅在首学时刻展示**，纯提示不设卡，零 FSRS 写入。首学时刻过后，升级仍可进行，但不再有推荐——用户在词条详情页自助发起。
3. **种子继承（seed）**：提前升级创建的 L2 行，初始 FSRS 状态从该词**跨书最佳 L2/L1 状态**一次性初始化，并记录 `seeded_from`。语义区分：**seed（一次性、用户显式触发）≠ merge（持续合并，仍禁止）**。
4. 升级在独立的 **agent 工作台**完成（内容校准 + 自我选择），agent 产出沿用 candidate pool 语义，未经用户采纳不生效（方向由工单指定，见 ADR-0017）。

## Tradeoffs

- **豁免门 vs 完整周期**：豁免可能被滥用导致过早晋升、L2 due 压力上升；以"建议纯提示 + 用户自负 + 可观测统计"对冲，且豁免仅限用户显式路径。若提前升级词的 L2 lapse 率显著高于自动晋升词，应回看本门槛。
- **seed 取他书最佳 vs 当前书 L1 状态**：当前书 L1 才约 1 天，在 L2 DR=0.90 下间隔会密集到劝退，提前升级功能将死于 due 压力；而取他书最佳违背"进度不合并"的纯粹性——以 seed/merge 语义区分解决：一次性初始化不是合并。
- **红线核对**：seed 是 L1/L2 **轨内**数据跨**词书**使用。ADR-0004 §6 隔离的是 L1/L2/L3 **轨道**（独立调度表/hash/weights），词书维度从未被红线约束——本 ADR 不触碰红线，只在词书维度开了"一次性、用户触发"的口子。
- **建议仅首学时刻展示 vs 常驻**：常驻会把"推荐"变成"催促"，与"人是决策者"的哲学冲突。

## Consequences

- ✅ 换书重叠词的 L2 升级成本大幅下降；agent 协作成为显式学习过程；增量认知闭环（L1 起步 → 建议 → 标记 → agent 升级）成立。
- ✅ "跨书数据只用于建议与一次性 seed"成为词书维度的补充规则；日常复习跨书零干扰不变。
- ⚠️ 需要观测提前升级词的 L2 lapse 率，作为门槛回看的依据。
- ⚠️ work-order 表与建议纯函数需落 schema 与 domain 层（domain 纯函数，零出向）。
