# ADR-0019: L3 练习记录与会话容器（有记录、无调度）+ 子空间两轴

- **Status**: Accepted
- **Date**: 2026-09-11
- **Amends**: CONTEXT.md 的 Context quiz stateless 适用范围（限定于词条页表面）；不修改 ADR-0004/0005 红线本身
- **References**: ADR-0004 §6（L3 不参与 FSRS）、ADR-0005（L3 边界）、ADR-0008（proposal 管线）、ADR-0017（方向）、CONTEXT.md（Session / Practice attempt / 错题库 / Sub-space）
- **上游**: 2026-09-11 增量认知设计拷问会话；TypeWords 架构评审（flow 版本化思想）

## Context

L3 此前只有 stateless 的 Context quiz（援引 Preview mode 先例：无记录、无调度、无自评），没有输出面。用户哲学：**只有输入没有输出的空间是有问题的**。作文攻坚等场景需要"强化练习和反复记忆"，但 "L3 owns no scheduling" 是红线（ADR-0004 §6 / ADR-0005）。

同时，素材需要按**能力域**组织（语法/阅读/作文/翻译），并与练习、错题打通——这是 L3 从"素材库"升级为"可分析可利用的资源空间"的结构前提。

## Decision

1. **L3 练习有记录、无调度**：新增 attempts 表（target：`context_id` 必选 + `occurrence_id` 可选；`session_id` 可空；`outcome`；**零 FSRS 写入**）。**错题库 = `attempts(outcome=wrong)` 的派生视图，不建表**（避免第二真相源）。
2. **会话（Session）= 慢学习容器**：服务端计划 + 实体引用渲染描述，**不存 HTML 产物**——每次打开现拉现渲染，素材更新与错题变化自动反映。会话承载：L2 升级工作台（ADR-0018）、L3 练习、知识梳理、攻坚包（时间盒计划，**有反复、无 FSRS**）。**L1 速刷卡不进会话**（<5s/词节奏不容会话开销）。
3. **第一梯队题型**：作文句默写 + 语境义自测（记录版）。词条页 Context quiz 保持 stateless——两个表面并存。
4. **子空间（能力域轴）与方向（考试轴）正交**：子空间为固定枚举（语法 / 阅读 / 作文 / 翻译 / 通用）；source 同时携带两轴、可属多个子空间（多对多）；知识点/方法论复用 `context_type='note'`（0 新表）；每个子空间排布 知识点/方法论 + 真题素材 + 错题库，信息间以跳转链接互联。

## Tradeoffs

- **会话化攻坚包 vs L3 局部调度**：攻坚是时间盒目标（考前 N 天），由计划驱动而非遗忘曲线；引入调度会推翻红线且当前无证据必要。若实测不够，须先立新 ADR 再谈。
- **攻坚素材晋升 L2 轨（复用既有 FSRS）**：把"句子"塞进"词"的轨道，语义错位，拒绝。
- **会话存计划+引用 vs 存渲染产物**：产物冻结会导致素材更新、错题变化不反映；计划+引用每次现渲染，天然稳定。
- **知识点复用 `context_type='note'` vs 独立实体**：枚举已存在，0 新表起步；若未来知识点需要独立生命周期（版本、评审）再拆。
- **attempt target = context（句子）而非 word**：L3 练习的作答对象是语境/句子，词级记忆由 L1/L2 承担。

## Consequences

- ✅ 输出闭环成立：素材 → 练习 → 记录 → 错题 → 再练习；"L3 不参与 FSRS"红线不动。
- ✅ Context quiz 的 stateless 语义范围被明确限定（仅词条页表面），"L3 一律无记录"的误读消除。
- ⚠️ attempts 持续增长，需要归档策略（参照 `review_logs_archive` 先例）。
- ⚠️ 会话渲染描述需要显式版本号（借 TypeWords 评审的 flow version 思路），非法版本拒绝恢复而非静默损坏。
- ⚠️ 子空间固定枚举是起步决策；用户自定义子空间是后期的事，届时需要新的结构决策。
