## 1. 体验目标

**核心命题（材料原文转译）**：空间的情感价值是**积累型（发现）而非消耗型（遗忘）**——
"卡片上的关系图越来越密，用户看到自己的知识网络在长大"（梳理文档 L548）。

可观测表达（四条验收锚点）：

| # | 锚点 | 可观测判据 |
|---|------|-----------|
| E1 | **开门第一眼是"我的"** | 进入 L3 空间默认看到素材宇宙（最近导入 / 最近圈记 / 生长计数），不是占位符、不是工程状态页 |
| E2 | **数字在生长** | 条目/圈记/关联的累计计数可见；数字只增不减（不因复习被消耗） |
| E3 | **痕迹被显形** | 阅读高亮密度 = 用户圈记的踪迹（Q7：仅已圈偏移并集——"高亮的不是词典，是你的踪迹"，梳理文档 L560）；空书架不尴尬 |
| E4 | **动线闭环** | 素材宇宙 → 阅读 / 词空间 / 图一键直达；阅读 ⇄ 词卡双向跳转（FR-6） |

**非目标（体验层明说）**：不做游戏化（等级/成就/徽章）；不做消费型催促（due 警示、连续打卡）；
"0 数据不预装筛选器"精神（梳理文档 L755）——空态不显示消极维度、不新增预设筛选。
（注：书架 c 完整版含类型筛选/搜索，系规模修正后的定案，L821 Q8，**不在本条目约束范围**。）

### 作文子空间 v1 锚点（2026-09-18 增补，随《writing-workspace》ADR）

作文子空间（`/l3?section=writing`）复用 E1/E3/E4 精神（首屏是用户自己的写作、修改痕迹可见、提交与回看贯通），另立五条可观测锚点：

| # | 锚点 | 可观测判据 |
|---|------|-----------|
| W1 | **动笔前最多一次确认** | 从列表/题库到光标进入正文，最多一次弹层（直接开始弹层或题库选择）；无连续确认墙 |
| W2 | **保存状态诚实** | 未保存/保存中/已保存/保存失败/版本冲突五态可见；网络故障不得出现"已保存"假象；失败给重试与复制 |
| W3 | **反馈明确对应稿次** | 反馈面板永远标注所属稿次（第 n 稿 + hash 基准）；旧稿反馈不叠加到新稿；无反馈=待评而非空白 |
| W4 | **离开再开不生成新稿** | 同一稿 URL 重开 / F5 → 同 sheetId 同正文；数据库零新增 draft；GET 一律只读 |
| W5 | **修改不覆盖旧稿** | 第二稿为新 sheet + 显式 parent 引用；第一稿只读原样；对照不宣分数提升 |

> W4 在 F-1（PR #121）已对 file/paper 档案建立先例（`?sheet=` 回看 F5 不新增纸）；本批将同语义扩大到写作稿。
> 验收截图与操作日志按《作文子空间》S§8 执行（十类截图、390×844 与 1440×900、明暗主题）。

## 4. 状态矩阵（每页 × 空/加载/错/满）

**文案总原则（积累型导向）**：空态 = "还没有 X → 做了 Y 它就会长出来"，禁止负面/空洞表达；
空态绝不出现"0 条"的空壳列表、不做催促；错误态与空态语义分离（既有 `l3ErrorUxContract` 契约已保证，回收测试兜底）。

### 素材宇宙（B1，本次重点）

| 态 | 表现 |
|----|------|
| **空**（sources=0） | 不渲染空的最近列表；显示引导块：「你的素材宇宙还很安静——导入第一篇文章，让它开始生长」+ 导入入口按钮；计数区显示 0 但带正向副标（如"从零开始，每一步都算数"）；不显示趋势图区（避免尴尬空坐标） |
| **加载** | 区块级 Skeleton（计数卡骨架 + 列表行骨架）；不用整页 spinner |
| **错** | 区块级错误提示 + 重试按钮（单区块失败不拖垮全页）；顶部无全局报错条 |
| **满** | 最近列表截断 5 条 + "查看全部 →"（链到书架）；数字千分位；趋势图窗口 30 天固定 |

### 其余页面（现状盘点基线，B4 统一时逐项核对）

| 页面 | 空 | 加载 | 错 | 满 |
|------|----|------|----|----|
| 书架 | 现文案"书架空空如也——导入第一篇文章吧"（走查核对语气） | 无 Skeleton（走查确认） | toast | 筛选器+搜索（c 完整版） |

## 5. 视觉 token 映射（沿用既有体系，不新造）

来源：`src/frontend/styles.css`（:root 与 [data-theme="dark"] 双套已齐）。

| 用途 | Token | 备注 |
|------|-------|------|
| 画布/背景 | `--color-canvas` / `--color-canvas-deep` + body 渐变资产 | 不动 |
| 卡/面板 | `--color-panel`（玻璃）、`--color-surface`（实心）、`--color-border`、`--shadow-panel` | 素材宇宙区块用实心 surface 系 |
| 文字 | `--color-ink`（主）/`--color-ink-soft`（辅） | 层级靠这两级 + 字号/字重 |
| 主强调（生长/行动） | `--color-accent` | 绿；数字/链接/主按钮 |
| 次强调（温暖） | `--color-accent-2` | 橙；点缀 |
| 高亮 | `--color-highlight` / `-key` / `-error` / `-root` / `-collocation` | 阅读理解用，不动 |
| 语义色 | rating/relation 系列 | 不动 |

**已知缺口（走查重点核实 → B4 修复）**：
`--color-accent-soft` 与 `--color-accent-contrast` 被组件大量使用（阅读高亮 mark、闪高亮动画、书架计数徽章、
ReviewCardView 的 L3 pill、按钮文字），但**全仓库未找到定义**（styles.css 无 `--color-accent-soft:` / `--color-accent-contrast:` 定义行）。
静态推断：相关背景色会静默失效（透明），`l3-focus-pulse` 动画可能整体失效。
**处置**：Step 2 走查截图实证 → 若确认失效，B4 在 :root / [data-theme=dark] 补定义（属"补既有体系缺口"，非新造体系）。
修复前，本次新增代码**允许继续引用这两个变量**（假定 B4 补齐），但必须在走查清单里留痕。

**密度与排版（沿用现状，不做全站改版）**：
- 圆角：`rounded-lg` / `rounded-xl`（卡与行）；徽章 `rounded-full`
- 文字：正文 13-13.5px，辅文 10-11.5px，页标题用既有 h2/h3 字体阶梯（**不引入新字号刻度**）
- 间距：区块间 `space-y-3`（12px）为基；卡内 padding 12-14px
- 布局宽度：沿用 `l3-main` 现有约束（宽屏阅读优先）

## 6. 动效与密度

**既有动效资产（沿用，不推翻）**：`rise-in`（页面入场）、`l3-focus-pulse`（深链闪高亮）、`l3-panel-slide-in`（面板滑入）。

**基线约定（新增动效只用这两条通道）**：
- 只承担"引导 + 反馈"两职能；时长 ≤ 0.25s；缓动不用弹跳/回弹；不引入动画库；
- 素材宇宙：数据加载完成用现有 `Reveal`/`rise-in` 级入场即可；**不做数字滚动动画**（克制；B2 若确有低成本高价值的生长微动效，需在 Gap 清单中单列说明后再定）；
- 密度：素材宇宙第一屏不塞满（三区块 + 轻标题）；列表行高沿用书架的 py-2 级别。

**B2 形态预选**（三候选：生长计数趋势 / 网络密度变化 / 时间轴）：
倾向 **生长计数趋势**（近 30 天每日新增：语境/圈词/关联），依据：① 直接呼应"数字在生长"（E2）；
② 数据面与 §7 的 byDay 聚合共用一条查询；③ 与最近列表不重复。
最终形态在 B2 启动时结合走查结论定稿并记录理由（**做一个，不做三个半成品**）。

## 7. 数据面计划（B1/B2 共用）

**复用优先（既有只读端点，零新增）**：

| 区块 | 端点 | 说明 |
|------|------|------|
| 最近导入 | `GET /l3/sources?sort=recent&limit=5` | 返回 id/title/source_type/created_at/context_count + total（书架同款） |
| 最近圈记 | `GET /l3/occurrences?limit=20` | **全局按 `created_at DESC`**（repo `l3-context.repository.ts:1082`）；前端按 context 聚合成 ≤5 组（句 + 词 chips） |

**新增端点（走完整 SOP）**：`GET /api/l3/space-summary`
- 依据：全量计数无法从既有端点获得（`/l3/graph` 的 stats 基于 limit 截断的子图；occurrences 为 cursor 分页无 total）。
- 形态（草案，实现时以 schema/契约讨论定稿）：
  `counts: { 素材数 / 语境数 / 圈词数 / 关联数 }` + `growth.windowDays=30 的 byDay 序列`。
- 纪律：schema → contract（`.strict()`）→ 薄路由（l3/index.ts 已受复杂度棘轮冻结，挂到独立薄路由文件，照 `l3/lists.ts` 先例）→
  `operations.ts` 登记 → `api:openapi` → `client:generate` → 前端消费 → `tests/http/` → `api:governance`（显式 base ref）。
- 只读、user-scoped、零写入（L3 红线不碰）。

**加载策略**：首页 3 请求并发（`Promise.all`），区块级独立降级（任一失败不影响其余区块渲染）。
