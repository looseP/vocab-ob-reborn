## 9. 常见问题预案

| 情况 | 处理 |
| --- | --- |
| 自检锚点不存在（文件/行号对不上） | 停止，汇报「环境不符」+ 实际所见 |
| 设计文档之间相互矛盾 | 以「完备设计」为准；仍矛盾则停止汇报 |
| `api:breaking` 报 UNKNOWN/BREAKING | 停止汇报；**禁止**重锚 approval |
| 路由复杂度棘轮拦新文件 | 在 `scripts/verify-route-complexity.ts` 的 bootstrap 清单加条目（按实测规模留一档余量），并照注释用 `ROUTE_COMPLEXITY_BASE_REF` 取证 |

| 想复用某个既有函数但会牵出 FSRS 写入 | 禁止复用；按完备设计新写 |
| 测试在本地环境跑不了（无 Postgres 等） | 标「环境受限」汇报；不得改测试 |
| 发现更「聪明」的实现方式 | 禁止采用；严格按定稿。把建议写进汇报的「风险与阻塞」，由主控裁决 |
