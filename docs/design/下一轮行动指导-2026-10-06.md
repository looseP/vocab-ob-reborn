## 5. 纪律与陷阱（开工前读一次）

1. **迁移三律**：journal `when` 严格递增（守卫在跑）｜快照链闭合（`db:generate` no-op 守卫在跑）｜**0051 起 DDL 幂等**（新 lint，"migrations from idx 51 are re-run safe"）。数据回填类语句用 `-- @idempotency-waive: <理由>`。
2. **账本真源**：改过 schema 的库（push/手工）先 `reconcile-migration-ledger report` 对账；新增迁移后必须让 `npm run rls:acceptance:verify` 的行数断言绿（否则静默跳迁移会被拦）。
3. **路由棘轮**：剩余空间恒为 0 —— 新端点新文件；新文件要在 `verify-route-complexity.ts` 登记 bootstrap 条目（上限=实测行数，含空行），并用 `ROUTE_COMPLEXITY_BASE_REF=<新增前的 ref>` 取证。
4. **一任务一 worktree**：本轮发生过共享工作树的分支串扰（提交一度落错分支，靠文件集不相交+复位修正）。并行会话必须分目录。
