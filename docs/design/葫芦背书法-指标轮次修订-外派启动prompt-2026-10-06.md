## 4. 已定案决策（禁止重新设计；违反任何一条 = 返工）

1. **「包含还没复习过的词」默认关**：创建表单新勾选，默认 = 现行先学后刷（`state ∈ ('learning','review','relearning')`）；开启 = 四态（含 `new`），同一稳定序 `created_at ASC, word_id ASC`。
2. **曝光轮 = `round_no = 0`、`kind = 'exposure'`**：仅 v2 + `include_new_words` 计划有；直展卡面（无遮答/无自认/无闸门）；页结算复用现有管道 `passed = total = 本页存活词数`（恒过闸，语义 = 已曝光）；**不计入** `target_rounds`；**不新增端点**（跳过 = 对第 0 轮调 `finishRound`）；完成度 <100% 允许显式跳过，计划页持续显示覆盖率缺口。
3. **复习轮词集恒等于定格词集**（只缩不换），不因曝光完成度缩减；复习轮页首提示「本批有 N 词在曝光轮未看过」（N ≈ `words_total − 曝光轮 words_passed`）。
4. **迁移 0051 手写 + 幂等**（ADR-0042 D4）：列与约束照补充稿 §六 的 SQL 逐字实现——`hulu_plans.protocol_version text NOT NULL DEFAULT 'legacy'`（CHECK 'v2'/'legacy'）、`hulu_plans.include_new_words boolean NOT NULL DEFAULT false`、`hulu_rounds.kind text NOT NULL DEFAULT 'legacy'`（CHECK 'exposure'/'recall'/'legacy'）、`hulu_rounds.word_set_fingerprint text`、`round_no` CHECK 放宽为 `>= 0 AND <= 8`。**存量行吃默认值，不回填指纹**。
5. **缩时只比可比较轮**：曲线只画 `kind ∈ ('recall','legacy')` 已收尾轮；基准 = 第一条 `kind='recall'` 已收尾轮（全 legacy 序列维持旧画法）；`word_set_fingerprint` 一致才算降幅，不一致的柱标「词集已变化，不与基准比较」；曝光轮耗时单列展示；免责声明追加第三条。**指纹计算在 service 层**（node:crypto SHA-256 取 hex 前 16 位；domain 零出向，只放 `huluSameWordSet(fpA, fpB)` 纯比较函数）。
6. **结算词集 = 页级近似**：轮收尾时按 `pages_passed` 游标取已结算页定格切片、过滤当前已删词（`findHuluPageWords`），排序后哈希。禁止建词级明细表。
7. **R15 两条防线**：`settlePage` 拒 `passed > total`（422）；`finishRound` 要求 `kind ∈ ('recall','legacy')` 的轮 `pages_passed = huluPageCount(word_count, page_size)`（否则 422 携带缺口），**曝光轮豁免**（部分收尾 = 显式跳过）。
8. **曝光轮不推进计划完成**：`finishRound` 仅对 `kind='recall'` 且 `round_no >= target_rounds` 时完成计划（同事务恢复挂起的既有逻辑不动）。
9. **指标分档**：曝光覆盖率（计划页徽章）、首次曝光耗时（单行，注明不计入对比）、每轮通过率文案 = 「过闸页自认通过数 ÷ 定格词数」；**首次回忆成功率不采、不展示、不留字段**，FAQ 一行说明。
10. **契约只增不改**：`huluPlanCreateSchema` 加 `includeNewWords?: boolean = false`；plan 响应加 `protocol_version` / `include_new_words`；round 响应加 `kind` / `word_set_fingerprint`（全部 `.strict()` 内新增字段）。端点恒为 7 条。
11. **空池双档文案**：默认档沿用现文案；开「含未学词」仍为空 → 「该词书还没有词——先把词加进词书再冲刺。」
12. **零 FSRS 写入红线不变**：曝光轮同样不写 `review_logs` / `user_word_progress`（挂起开关例外照旧）。

| 情况 | 处理 |

| 0051 幂等 lint 报某句不幂等 | 对照 ADR-0042 D4 改写（IF [NOT] EXISTS / DROP IF EXISTS + ADD）；数据回填类才可用 `-- @idempotency-waive: <理由>`，本轮没有回填类语句 |

| 既有 service 测试因 `insertRound`/`finishRound` 入参变化挂 | 更新 mock 断言到新签名（允许），核对新断言真的覆盖 `kind`/指纹 |
