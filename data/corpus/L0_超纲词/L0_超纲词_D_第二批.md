## disposable

### Identity
- lemma: disposable
- title: disposable
- pos: adj
- ipa: /dɪˈspəʊzəbl/
- cefr: B2
- aliases: dispose, disposal, disposition, disposably

### Short Definition
一次性的；可丢弃的；可自由支配的

### Core Definitions
1. 一次性的；用后可丢弃的
   - en: intended to be thrown away after use
   - priority: 1
   - tags: A
2. 可自由支配的
   - en: available to be used as one wishes
   - priority: 2
   - tags: B

### Prototype
disposable = 用完后可以放到一边，或把资源安排给某种用途。

### Morphology
- prefix: dis- (apart, away)
- root: pos (put, place)
- suffix: -able
- family: dispose, disposal, disposition

### Etymology Narrative
来自 dispose + -able；dispose 源自拉丁 disponere“安排、分配、放置”，由 dis- 与 ponere“放置”构成，现代 disposable 可指用后丢弃，也可指资源可支配。 

### Mnemonic
- type: root
- text: pos = put/place：能被安排出去，也能用后放掉 = disposable。

### Semantic Chain
摆出来 -> 备着随时取用 -> 用完就扔 -> 一次性的

## disruptive

### Identity
- lemma: disruptive
- title: disruptive
- pos: adj
- ipa: /dɪˈsrʌptɪv/
- cefr: C1
- aliases: disrupt, disrupted, disruption

### Short Definition
破坏性的；扰乱的；颠覆性的

### Core Definitions
1. 扰乱的；破坏性的
   - en: causing serious problems by interrupting a process or system
   - priority: 1
   - tags: A
2. 颠覆性的
   - en: radically changing an established industry or way of doing things
   - priority: 2
   - tags: B

### Prototype
disruptive = 原本连续运转的结构被突然打断。

### Morphology
- prefix: dis- (apart)
- root: rupt (break)
- suffix: -ive
- family: disrupt, disruption

### Etymology Narrative
来自拉丁语 disruptus“打破、撕裂”，由 dis- 与 rumpere“打破”构成；disruptive 描述打断系统，也可指带来根本变化。 

### Mnemonic
- type: root
- text: rupt = break，dis- = apart：把连续系统打破就是 disruptive。

### Semantic Chain
破开 -> 从中打断 -> 搅乱了整套 -> 扰乱的、破坏性的
