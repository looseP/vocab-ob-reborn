## science

### Identity
- lemma: science
- title: science
- pos: n
- ipa: /ˈsaɪəns/
- cefr: A2
- aliases: sciences

### Short Definition
科学；自然科学；学科；系统知识

### Core Definitions
1. 通过观察、实验和推理建立起来的系统知识
   - en: organized knowledge built through observation, testing, and reasoning
   - priority: 1
   - tags: A
2. 自然科学，或与 arts / humanities 相对的一类科学领域
   - en: the natural sciences, or a science field contrasted with arts and humanities
   - priority: 2
   - tags: B
3. 某一门系统研究的学科
   - en: a branch of study or disciplined body of knowledge
   - priority: 3
   - tags: C

### Prototype
science = 同一件事试了一百次，把规律找出来记成本子

### Morphology
- prefix: none
- root: sci-/scient- / Latin *scientia*, *scire* (knowledge, know, distinguish)
- suffix: none
- family: science, scientific, scientist, conscience, conscious

### Etymology Narrative

仓内 `science.md` 把 *science* 放在 拉丁语 *scientia* “知识、了解、技能” 这一条线上，并进一步连到 *scire* “知道”。它最有价值的地方，是保留了一个很稳定的语义中心：先是“能够分辨、能够知道”，随后变成“知识本身”，再进一步专指“系统化的知识”，于是现代英语里的 *science* 就自然覆盖了“科学”“自然科学”“某门学科”这些常见义项。
### Mnemonic
- type: image
- text: 拉丁语 scientia 出自 scire（知道）→ 从“能分辨、能知道”，到把这些知见排成了体系。

### Semantic Chain
辨析 -> 求得真知 -> 成体系之学 -> 科学

### Reviewer Notes
- 仓内 `science.md` 明确采用 `Old French science -> Latin scientia -> scire` 的主线，并把中心语义收束为“知道/知识”。
- 本轮不等待网络，因此没有再核对它更深层与“分开、辨别”相关的 PIE 细节，只保留“知道 -> 知识 -> 科学/学科”这条稳定链。
- No aliases; `sciences` 只是普通复数形式，不作 alias。
- confidence: uncertain

## seem

### Identity
- lemma: seem
- title: seem
- pos: v
- ipa: /siːm/
- cefr: A2
- aliases: seems, seemed, seeming

### Short Definition
似乎；看来；显得

### Core Definitions
1. 似乎，好像是某种情况
   - en: to appear to be the case
   - priority: 1
   - tags: A
2. 看起来处于某种状态或给人某种印象
   - en: to give the impression of being in a certain state
   - priority: 2
   - tags: C
3. 按表面迹象看来如此，而不是直接断言事实
   - en: to look or sound true on the basis of appearances rather than certainty
   - priority: 3
   - tags: C

### Prototype
seem = 远远看着像他，走近了才发现不是

### Morphology
- prefix: none
- root: seem-/soem- / Old Norse *soema*, *soemr*, Proto-Germanic *somiz* (fit, proper)
- suffix: none
- family: seem, seeming, seemingly, seemly, unseemly

### Etymology Narrative

仓内 `seem.md` 明确把 *seem* 的早期中心放在 古诺尔斯语 *soema* / *soemr* 一类“合适、得体”的线上，再把现代英语的义项解释为一次很自然的语义漂移：某物先是“看起来合适”，接着变成“看起来像”“似乎如此”。这条线能很好统一今天最常见的用法——*seem happy*、*it seems that...*、*seem to do*——因为它们都不是在硬性断言事实，而是在描述表面呈现出的印象。
### Mnemonic
- type: image
- text: 与 same 同族，本义是“看着像、合乎样”→ 面上露着那个样子，底里究竟如何还两说。

### Semantic Chain
相宜 -> 看着像样 -> 呈其表象 -> 似乎

### Reviewer Notes
- 仓内 `seem.md` 明确采用 `Old Norse soema/soemr -> fit/proper -> appear` 的路线，并把现代义统一到“表面呈现出的样子”。
- 本轮未联网复核它与 `same` 的更远同源关系，以及各语义阶段的精确年代，因此只保留“合适 -> 看起来像 -> 似乎”主线。
- No aliases; `seemed`、`seems`、`seeming` 等普通屈折或派生形式不作 alias。
- confidence: uncertain

## seemingly

### Identity
- lemma: seemingly
- title: seemingly
- pos: adv
- ipa: /ˈsiːmɪŋli/
- cefr: B2
- aliases: 

### Short Definition
表面上；看来；似乎

### Core Definitions
1. 表面上看起来如此
   - en: apparently so on the surface
   - priority: 1
   - tags: A
2. 似乎、看来，用来修饰一种不完全确定的判断
   - en: in a way that appears to be true without complete certainty
   - priority: 2
   - tags: B
3. 常暗示实际情况也许并不完全如表面所见
   - en: often suggesting that reality may differ from outward appearance
   - priority: 3
   - tags: C

### Prototype
seemingly = 看着顺顺当当，底下的账其实对不上

### Morphology
- prefix: none
- root: seem- / English *seem* from the Old Norse *soema* line
- suffix: -ingly (adverbial layer from *-ing* + *-ly*)
- family: seem, seeming, seemingly, seemly, unseemly

### Etymology Narrative
仓内 `seemingly.md` 采取的是非常稳妥的英语内部构词解释：*seem* + *-ing* + *-ly*。也就是说，这个词不需要额外另找一条独立词源线，它本身就是“呈现出某种样子”这个判断被副词化之后的结果。这样一来，*seemingly simple*、*seemingly unrelated*、*seemingly endless* 等表达就都能统一在一个中心上：某件事在表层观察下显得如此，但说话人通常并没有把它当成最终事实。 

### Mnemonic
- type: image
- text: seem + -ing + -ly → 只是初看时呈出那么一副模样；究竟如何，还得再往里头瞧。

### Semantic Chain
看着像 -> 表面模样 -> 仅止皮相 -> 表面

### Reviewer Notes
- 仓内 `seemingly.md` 明确按 `seem + -ing + -ly` 的英语内部派生处理，语义重心是“表面上看来如此”。
- 本轮未联网复核它最早书面出现时间，也没有把全部语境都写成“必然暗示相反事实”，只保留“常带表面性”的稳妥描述。
- No aliases; 相关形式如 `seem`、`seeming` 只放在 family，不作 alias。
- confidence: uncertain

## selection

### Identity
- lemma: selection
- title: selection
- pos: n
- ipa: /sɪˈlekʃən/
- cefr: B1
- aliases: selections

### Short Definition
选择；挑选；精选品；可选范围

### Core Definitions
1. 挑选、选择的行为或过程
   - en: the act or process of choosing
   - priority: 1
   - tags: A
2. 被选出来的一组东西或精选品
   - en: a set of things chosen out from a larger group
   - priority: 2
   - tags: C
3. 可供选择的范围或品类
   - en: the range of options available to choose from
   - priority: 3
   - tags: C

### Prototype
selection = 一筐里挑出十只，剩下的倒回去

### Morphology
- prefix: se- (apart)
- root: lect-/lig- / Latin *legere* via *selectus*, *selectio* (gather, choose)
- suffix: -ion (action or result noun layer)
- family: select, selection, selective, selector, selected

### Etymology Narrative
仓内 `selection.md` 用的是最清晰的一条构词线：*select* + *-ion*，并把更深层背景收束到“从许多东西里分离、挑出”的动作图像上。往拉丁层回看，这一条线与 *selectus* / *selectio* 及更深的 *legere* “采集、选择”相连，因此 *selection* 很自然地同时覆盖三类现代用法：选择这个动作、被选出的结果，以及供人挑选的一批范围或品类。 

### Mnemonic
- type: image
- text: select（挑出）+ -ion → 从一大堆里分出来、拣走的那一批；也指拣这个动作本身。

### Semantic Chain
收拢 -> 择而取之 -> 拣选行为 -> 选择

### Reviewer Notes
- 仓内 `selection.md` 明确采用 `select + -ion` 的英语可见构词，并把中心义统一到“挑出、选出”。
- 本轮未联网逐字核对它在拉丁层究竟以 `selectio` 还是 `selectus -> selection` 的哪一条叙述最合适，因此只保留“挑选/分出”这一稳定主线。
- No aliases; `selections` 只是普通复数形式，不作 alias。
- confidence: uncertain

## self

### Identity
- lemma: self
- title: self
- pos: n/pron/adj
- ipa: /self/
- cefr: B1
- aliases: selves

### Short Definition
自己；自我；本身；自身的

### Core Definitions
1. 一个人自己、其身份或本我
   - en: a person’s own identity or essential being
   - priority: 1
   - tags: A
2. 用于强调“本人、本身”
   - en: the person or thing itself, used for emphasis
   - priority: 2
   - tags: C
3. 作为构词成分表示“自身的、关于自己的”
   - en: as a modifier meaning relating to oneself or itself
   - priority: 3
   - tags: C

### Prototype
self = 镜子里那张脸，谁也替不了

### Morphology
- prefix: none
- root: self-/seolf- / Old English *seolf*, Proto-Germanic *selbaz*, PIE *s(w)e-* (self, own person)
- suffix: none
- family: self, selfish, selfless, oneself, selfhood

### Etymology Narrative

仓内 `self.md` 把 *self* 作为一个非常核心的日耳曼原生词来处理：古英语 *seolf*，再往上可连到 原始日耳曼语 *selbaz*，并和更深层“自己”意义的印欧背景相关。这个词的语义中心几乎没有漂移：它始终指向“自己本身”。也正因为这个中心太稳，所以现代英语里无论是名词 *the self*、强调用法里的“本人/本身”，还是 *self-interest*、*self-awareness* 这类复合词，都可以回收到同一个核心画面里。
### Mnemonic
- type: image
- text: 古英语 seolf，日耳曼原生词 → 你指着镜子里那个人时用的字眼，千年来指的都是同一样。

### Semantic Chain
自身之人 -> 本己 -> 个人身份 -> 自我

### Reviewer Notes
- 仓内 `self.md` 明确把 *self* 作为 `Old English seolf -> Proto-Germanic selbaz` 的日耳曼原生词处理，核心就是“自己本身”。
- 本轮没有联网复核它在古英语和更早层面的具体拼写分布，因此只保留“自己/本身”的稳定主线，不扩写更细的历史分支。
- No aliases; `oneself`、`himself`、`selfish` 等相关形式只放在 family，不作 alias。
