## literally

### Identity
- lemma: literally
- title: literally
- pos: adv
- ipa: /ˈlɪtərəli/
- cefr: B2
- aliases: literal-mindedly

### Short Definition
按字面地；确实地；用于强调而非字面地

### Core Definitions
1. 按字面地；按词语的准确意义
   - en: in a literal or exact sense
   - priority: 1
   - tags: A
2. 确实地；真实地
   - en: actually or genuinely
   - priority: 2
   - tags: B
3. 用于夸张或隐喻中的强调
   - en: used as an intensifier even when the statement is not literally true
   - priority: 3
   - tags: B

### Prototype
literally = 把话语按“文字本身”来理解；现代口语又把它借作强强调词，甚至用于非字面夸张。

### Morphology
- prefix: none
- root: literalis / Latin *litera, littera* (letter, writing)
- suffix: -ly (Germanic adverbial layer)
- family: literal, literality, literally, literal-minded

### Etymology Narrative

约1530年代已见，意为“按字面义、依所用词语的确切含义”，由 literal 加 -ly 构成。底层的 literal 出自晚期拉丁语 literalis / litteralis（属于字母或书写的），源自拉丁语 litera / littera（字母、书写符号；文字、书本）。画面是照着写下来的字句原样理解。17世纪末起引申入比喻与夸张，遂产生现代用作强调的口语用法，反而与原本“确切”之义相冲突。
### Mnemonic
- type: image
- text: letter 是文字单位，literal 是按文字本身，literally 就是“按字面地”；现代语气中还可表示“真的、简直”。

### Semantic Chain
字母文字 -> 关乎字句 -> 字面上的真义 -> 按字面地；按词语的准确意义

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/literally；精确形式为 1530s *literally* < *literal* + *-ly*；underlying *literalis/litteralis* < Latin *litera/littera*。
- `-ly` 是英语/日耳曼副词层；不把 `liter-` 当作可自由组合的现代英语词根，也不把 `literally` 与 literary 视为别名。
- `literal-mindedly` 仅作常用替代表达；不加入含本词 lemma 的复合自指形式。
- confidence: source-backed

### Mnemonic

### Semantic Chain

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/literary；精确形式为 1640s *literary* < French *littéraire* < Latin *literarius/litterarius* < *littera/litera*；文学义 1737。
- `-ary` 作为历史形容词层可说明，但不把现代拼写硬拆成 `liter + -ary`；literary 与 literally 是同源近形词，不是 aliases。
- `literarily` 是副词替代形式；不加入 `literary` 的复合词。

- title: locality
- pos: n
- ipa: /loʊˈkæləti/
- cefr: C1
- aliases: localities

### Short Definition
地方性；地点；某一地区

### Core Definitions
1. 地方；地区
   - en: a particular place or district
   - priority: 1
   - tags: A
2. 地方性；具有局部地点的性质
   - en: the fact or quality of having a place
   - priority: 2
   - tags: B
3. 局部范围
   - en: the condition of being restricted to a particular area
   - priority: 3
   - tags: C

### Prototype
locality = 往东再走三里，口音就变了

### Morphology
- prefix: none
- root: localis / Latin *locus* (place, spot)
- suffix: -ity (Latin/French abstract noun layer)
- family: local, locality, localize, location, locate

### Etymology Narrative

约1620年代已见，意为“具有位置这一事实”，源自法语 localité，出自晚期拉丁语 localitatem（主格 localitas），本指物体“处于某处”的属性，由 localis（属于某地的）派生，而 localis 出自拉丁语 locus（地方、处所）。具体的“某一地理处所或地区”一义始见于1830年。
### Mnemonic
- type: image
- text: local 指某地，-ity 把“属于某地”变成性质；locality 就是一个地方或地方性。

### Semantic Chain
处所地点 -> 属某地 -> 有处所这回事 -> 地理片区 -> 地方；地区

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/locality；精确形式为 1620s *locality* < French *localité* < Late Latin *localitas/localitatem* < *localis* < Latin *locus*；geographical sense 1830。
- `-ity` 是历史抽象名词层；不把 `loc-` 与 `-al-` 再机械细分为现代英语多重后缀。*locus* 的更深来源不确定，但本词的直接路线清楚。
- location 与 locality 共享 *locus* 背景，但 locality 偏“地方/地方性”，location 偏“放置或定位所得的位置”；不互列 aliases。
- confidence: source-backed

### Short Definition
位置；地点；定位或放置

### Core Definitions
1. 位置；地点
   - en: a particular position or place
   - priority: 1
   - tags: A
2. 放置；定位行为
   - en: the act or condition of placing or locating something
   - priority: 2

   - en: a place outside a studio where a film scene is shot
   - priority: 3
   - tags: C

### Prototype
location = 地图上一个红点，钉在河西岸

### Morphology
- prefix: none
- root: locatio / Latin *locare* < *locus* (placing, place)
- suffix: -ion (Latin/French action noun layer)
- family: locate, location, locative, locality, localize

### Etymology Narrative

约1590年代已见，意为“位置、地点；处在某处的事实或状态”，源自拉丁语 locationem（主格 locatio），意为“放置”，是 locare（安放、置放）过去分词词干派生的动作名词，而 locare 出自 locus（地方）。画面是把东西放到某处、各有其所。安放安置、勘定的地块、影片外景地等义后起。
### Mnemonic
- type: image
- text: locate 是把东西放到地图上，-ion 是这个动作或结果；location 就是定位后的地点。

### Semantic Chain
处所 -> 安放设定 -> 摆放之举 -> 固定之位 -> 位置；地点

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/location；精确形式为 1590s *location* < Latin *locationem/locatio* < *locare* < *locus*；placing/settling 义 1620s，film sense 1914。
- `-ion` 是历史行动名词层；不把 `locate` 的现代拼写和拉丁 *locare* 当作完全同步的英语派生关系。
- locality 是地点/地方性的名词，location 是放置、定位或位置的名词；两者同源但语义原型不同，不互列 aliases。
- confidence: source-backed

- pos: adj
- ipa: /ˈlɑːdʒɪkəl/
- cefr: B2
- aliases: logically

### Short Definition
合乎逻辑的；合理的；逻辑学的

### Core Definitions
1. 合乎逻辑的
   - en: following the principles of valid reasoning
   - priority: 1
   - tags: A
2. 合理的；自然推出的
   - en: following as a reasonable consequence
   - priority: 2
   - tags: B
3. 逻辑学的
   - en: relating to logic as a field of study
   - priority: 3
   - tags: B

### Prototype
logical = 一个结论能从前提中按合理规则推出；由此也可泛指做法合理、顺理成章。

### Morphology
- prefix: none
- root: logikos / Greek *logos* (reason, word, account)
- suffix: -al (adjectival layer)
- family: logic, logical, logically, illogical, logician

### Etymology Narrative

约15世纪初已见，意为“基于理性的、合乎逻辑原理的”，由 logic 加 -al 构成。名词 logic 经古法语与拉丁语溯至希腊语 logike（推理之术），出自 logikos（属于言说或推理的），基于 logos（理性、思想、言辞）。画面是把话说得在理、讲得通。“作为合理的结果而随之而来”一义始见于1860年。
### Mnemonic
- type: image
- text: logos 是 reason/word；logic 是推理系统，logical 就是符合这个系统或因此显得合理。

### Semantic Chain
言辞陈说 -> 道理 -> 有效推理之学 -> 依乎逻辑 -> 合乎逻辑的

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/logical；精确形式为 early 15c. *logical* = *logic* + *-al*；logic < Old French < Latin < Greek *logike/logikos* < *logos*。
- `-al` 可作为英语形容词层；`log-` 不应被误写成“日志”词根，现代意义须以 Greek *logos* 的 reason/word 路线为准。
- `illogical` 是反义派生，不是 aliases；`logically` 是本词的副词形式。
- confidence: source-backed

## lower

### Identity
- lemma: lower
- title: lower
- pos: adj/adv/v

- cefr: B1

### Short Definition
较低的；降低；使下降；皱眉阴沉

### Core Definitions
1. 较低的
   - en: situated below or less high than another
   - priority: 1
   - tags: A
2. 降低；使下降
   - en: to descend or cause something to descend
   - priority: 2
   - tags: B
3. 减少；降低水平或价格
   - en: to reduce an amount, level, or value
   - priority: 3
   - tags: C
4. 阴沉地皱眉
   - en: to look dark and menacing or frown
   - priority: 4

### Prototype
lower = 相对于基准处在更低位置，或使某物向下移动；另有同形词表示脸色阴沉、皱眉。

### Morphology
- prefix: none
- root: low / Middle English *lawar, lower*; separate verb *louren/luren*
- suffix: -er (Germanic comparative layer for the adjective; not the source of the separate verb)
- family: low, lower, lowest, lowering, lowly

### Etymology Narrative

比较级形容词在中古英语中作 lawar、lower、lougher，更早作 lahre，由 lah（低）而来；副词用法始于1540年代。动词“下降、下沉、变低”约1600年出现，本为 low 的比较级动词化；及物义“使下降”始于1650年代。另有一词 lower / lour，意为“面露阴沉、皱眉”，出自中古英语 louren / luren，其词形大概是后来向上述比较级动词靠拢的结果，与本词并不同源。
### Mnemonic
- type: image
- text: low 加比较级 -er 就是 lower；但 lower/lour“皱眉”是另一条历史线，记作阴沉的脸而不是向下移动。

### Semantic Chain
低 -> 更低 -> 低于参照 -> 降下削减 -> 较低的

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/lower；比较级为 Middle English *lawar/lower/lougher* < *lah*；动词 v.1 约 1600，v.2 “look dark and menacing”来自 Middle English *louren/luren*。
- `-er` 仅说明比较级层，不把它套用于另一个 lower/lour 动词；“降低”和“皱眉阴沉”必须分开。
- `lowered`、`lowering`、`lowers` 是动词屈折形式；`lower` 自身不是 aliases，避免自指。
- confidence: source-backed

### Mnemonic
- type: image
- text: lucre 是 profit，lucrative 就是“能带来 lucre 的”，即有利可图的。

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/lucrative；精确形式为 early 15c. *lucrative* < Old French *lucratif* / Latin *lucrativus* < *lucratus* < *lucrari* < *lucrum*。

- confidence: source-backed
