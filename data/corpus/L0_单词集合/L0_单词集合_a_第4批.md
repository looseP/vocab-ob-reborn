## actual

### Identity

- lemma: actual
- title: actual
- pos: adj
- ipa: /ˈæktʃuəl/
- cefr: B1
- aliases: actuality

### Short Definition

实际的；真实的

### Core Definitions
1. 实际的；真实存在的
   - en: existing in fact; real
   - priority: 1
   - tags: A
2. 目前的；确切的
   - en: current or precise, as opposed to supposed
   - priority: 2
   - tags: C

### Prototype
actual = 账上写的和库房里数的，差了十七件

### Morphology

- prefix:
- root: act (Latin actus, agere "to do, drive")
- suffix: -ual
- family: act, active, action, agent

### Etymology Narrative
 源自晚期拉丁语 actualis（属于行动的），是拉丁语 actus（一个行为、所做的事）的形容词形式，而 actus 出自 agere（做、驱动，PIE *ag-）。画面是正在动手去做的那件事。凡实际做出来的便是实在的，故有“实际的”一义。 

### Mnemonic

- type: root
- text: act（agere 做）+ -ual：真正在做、在发生的，就是 actual 实际的。

### Semantic Chain
做 -> 正在做 -> 落于行动 -> 实际的；真实存在的

### Reviewer Notes

- Keep.
- 无 ad- 前缀；root agere；与 act/active/agent 同族。
- confidence: source-backed
