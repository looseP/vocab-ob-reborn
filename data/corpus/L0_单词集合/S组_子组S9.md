## setting

### Identity
- lemma: setting
- title: setting
- pos: n
- ipa: /ˈsetɪŋ/
- cefr: B1
- aliases: settings

### Short Definition
环境；背景；情境；设置值

### Core Definitions
1. 某事发生的环境、背景或场所
   - en: the environment, background, or place in which something happens
   - priority: 1
   - tags: A
2. 小说、戏剧、电影等的时代与场景背景
   - en: the time and place in which a story, play, or film is set
   - priority: 2
   - tags: C
3. 设备、系统或程序中预先设定的参数
   - en: a level or option that has been set on a device, system, or program
   - priority: 3
   - tags: C

### Prototype
setting = 故事发生在江边小镇，一开场就是雨天

### Morphology
- prefix: none
- root: set-/sett- / Old English *settan* (place, cause to sit)
- suffix: -ing (noun layer)
- family: set, setting, settings, settle, settlement

### Etymology Narrative
仓内 `setting.md` 直接把这个词写成 `set + -ing`，并用“被放置的背景或环境”来统筹全词。这个抓手很稳：一件事发生在某个 setting 里，就是它被放到某个环境中；故事有 setting，是情节被安放在某个时代与地点里；相机或系统里的 settings，则是参数被预先放定后的状态。离线重构时，只要守住“放到位、放成某种状态”这条主线，几个常见义项就能自然连起来。 

### Mnemonic
- type: image
- text: set + -ing → 事情被安放在怎样一处周遭里：故事搁在哪个年头、哪块地界。

### Semantic Chain
安放 -> 就位于此 -> 周遭之景 -> 背景

### Reviewer Notes

- prefix: none

### Semantic Chain
安顿 -> 落定下来 -> 成其稳局 -> 和解

### Reviewer Notes

### Core Definitions

   - en: the form or outline of an object
   - priority: 1

   - en: to give form to something or mold it into a shape
   - priority: 2

   - en: to influence the development, direction, or result of something
   - priority: 3
   - tags: B

### Prototype
shape = 泥在手里转着转着，就成了一只罐

### Morphology
- prefix: none
- root: shape-/shap- / probable Old English *gesceap*, *sceapian* (form, create)
- suffix: none
- family: shape, shaped, shaping, shapeless, reshape

### Etymology Narrative

核心就是「形」与「赋形」。可以把它理解成一条较老的日耳曼语「成形／创造」（form/create）线：先有东西呈现出的外轮廓，再有把材料塑出外形的动作，最后才延伸到抽象层面的塑造——如经历塑造一个人（shape a person），政策塑造一个市场（shape a market）。名词义和动词义不会分裂，都围绕「成形」展开。
### Mnemonic
- type: image
- text: 一条日耳曼语的“成形／创造”线 → 材料被塑出的那个外轮廓；把泥捏出个样子，也是它。

### Semantic Chain
塑成 -> 显出轮廓 -> 赋以形貌 -> 形状

### Reviewer Notes
- 仓内 `shape.md` 以“形状 -> 赋形 -> 影响发展”作为稳定主线，足以支撑本轮九段重构。

### Semantic Chain
