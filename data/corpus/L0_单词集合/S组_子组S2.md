## scientific

### Identity
- lemma: scientific
- title: scientific
- pos: adj
- ipa: /saɪənˈtɪfɪk/
- cefr: B1
- aliases: 

### Short Definition
科学的；合乎科学方法的；系统而精确的

### Core Definitions
1. 与科学研究或知识体系有关的
   - en: relating to science, research, or organized knowledge
   - priority: 1
   - tags: A
2. 符合科学方法与证据标准的
   - en: based on scientific method, testing, or evidence
   - priority: 2
   - tags: C
3. 做法系统、精确、客观的
   - en: systematic, exact, and objective in approach
   - priority: 3
   - tags: C

### Prototype
scientific = 结论不是拍脑袋来的，每一步都有数据撑着

### Morphology
- prefix: none
- root: sci-/scient- / Latin *scientia*, *scire* (knowledge, know)
- suffix: -ific (Latin adjectival or factive layer from *-ficus*)
- family: science, scientific, scientist, scientifically

### Etymology Narrative

学术性构词：建立在 science 之上，往上可追到拉丁语 scientia（知识）与 scire（知道），并带有 -ficus／-ific 的形容词层。词的中心不只是「跟实验室有关」，而是「跟可靠地产生知识有关」，因此自然延伸出「合乎科学方法」「系统而精确」这些现代常用义。
### Mnemonic
- type: image
- text: scientia（知识）打底 → 中心不是“跟实验室有关”，而是“能可靠地产出知识”的那套法子。

### Semantic Chain
认知 -> 成其学问 -> 循证之法 -> 科学

### Reviewer Notes
- 仓内原词条明确给出 *science* / *scientia* / *scire* 与 *-fic* 的构词线，但本轮未联网逐字复核 Etymonline 页面。
- “系统、精确”保留为科学方法品质的延伸义，不另造新词根分支。
- No aliases; `scientifically` 属于 family，不作 alias。
- confidence: uncertain

## scope

### Identity
- lemma: scope
- title: scope
- pos: n/v
- ipa: /skəʊp/
- cefr: B2
- aliases: scopes, scopes, scoped, scoping

### Short Definition
范围；余地；观察仪器简称；审视评估

### Core Definitions
1. 活动、研究或影响所及的范围
   - en: the range or extent covered by an activity, study, or influence
   - priority: 1
   - tags: A
2. 可以发挥或改进的空间
   - en: room or opportunity for action, growth, or improvement
   - priority: 2
   - tags: C
3. 观察仪器的简称；引申为审视、勘察
   - en: a shortened form for an observing instrument, or to examine carefully
   - priority: 3
   - tags: B

### Prototype
scope = 站在山口放眼望，能看到的那一片都归他管

### Morphology
- prefix: none
- root: scop-/skop- / Greek *skopos*, *skopein* (target, watcher, examine)
- suffix: none
- family: scope, scoped, scoping, telescope, microscope

### Etymology Narrative

核心放在希腊语 skopos（目标、观察者）与 skopein（看、检查）上，并提示英语的「范围」义可能经意大利语 scopo 这一路进来。无论具体中介路径怎样，中心都很稳定：先是「看或瞄准的对象／视野」，再扩展为「活动能覆盖的范围」，最后才有现代英语里「发挥余地」和口语动词「审视、踩点」这些分支。
### Mnemonic
- type: image
- text: 希腊语 skopein（看、观察）→ 目光扫过去能罩住的那一片，也就是事情够得着的边。

### Semantic Chain
望而定位 -> 目视所及 -> 所涉幅度 -> 范围

### Reviewer Notes
- 仓内原词条的 `word_root` 一栏曾标注“待确认”，所以这里保留 Greek *skop-* 路线但不把中介细节写死。
- 仪器简称义和现代动词义都视为英语内部的后起分支，不回拆成独立词源。
- No aliases.
- confidence: uncertain

## scorn

### Identity
- lemma: scorn
- title: scorn
- pos: n/v
- ipa: /skɔːrn/
- cefr: C1
- aliases: scorns, scorns, scorned, scorning

### Short Definition
轻蔑；嘲弄；鄙视；不屑于

### Core Definitions
1. 强烈的轻蔑或鄙视
   - en: intense contempt or disdain
   - priority: 1
   - tags: A
2. 带着讥讽意味的嘲弄
   - en: mocking ridicule that expresses contempt
   - priority: 2
   - tags: C
3. 因瞧不起而拒绝接受或去做
   - en: to reject or refuse because one considers something beneath notice
   - priority: 3
   - tags: C

### Prototype
scorn = 不只是“看不起”，而是把对象通过嘲笑和鄙夷往下压，公开表明它不值得尊重。

### Morphology
- prefix: none
- root: scorn-/escarn- / Old French *escarn*, Germanic *skarnjan* (mock)
- suffix: none
- family: scorn, scornful, scornfully, scorner

### Etymology Narrative

仓内词条把 *scorn* 追到 古法语 *escarn* 与 *escharnir* 一支，再往下连到一个 日耳曼语 的“嘲笑、戏弄”动词层。这个历史很适合解释现代词义：先是公开嘲弄，随后固定成强烈鄙视的态度，再延伸出 *scorn to do sth.* 这种“因轻蔑而不屑去做”的用法。也就是说，*scorn* 的核心不是冷静评价，而是带刺的、压低对方价值的蔑视。
### Mnemonic
- type: image
- text: 溯至古法语 escarn（嘲弄）→ 先是当面奚落，日子久了就凝成一股瞧不上人的态度。

### Semantic Chain
嘲弄 -> 公然奚落 -> 视若等闲 -> 轻蔑

### Reviewer Notes
- 仓内原词条还提到更深层的 Germanic 解释存在分歧，因此这里不把最深词根关系写成定论。
- `scorn to do` 保留为“鄙视而拒绝”的语义延伸，不另立新分支。
- No aliases.
- confidence: uncertain

## secure

### Identity
- lemma: secure
- title: secure
- pos: adj/v
- ipa: /sɪˈkjʊr/
- cefr: B1
- aliases: secures, secured, securing

### Short Definition
安全的；稳固的；安心的；保护并取得

### Core Definitions
1. 安全、受保护或固定牢靠的
   - en: safe, protected, or firmly fixed
   - priority: 1
   - tags: A
2. 心里有把握、没有忧虑的
   - en: confident or free from anxiety
   - priority: 2
   - tags: C
3. 保护、固定、取得或确保某物
   - en: to protect, fasten, obtain, or make something certain
   - priority: 3
   - tags: B

### Prototype
secure = 把危险或忧虑移开，于是人会安心，物会稳固，结果也会变得更确定、更容易“拿到手”。

### Morphology
- prefix: se- (apart, away; forming a free-from sense)
- root: cur- / Latin *cura* (care, concern)
- suffix: none
- family: secure, security, securely, insecure, insecurity

### Etymology Narrative

直接连到拉丁语 securus（无忧的），也就是把 cura（忧虑、关切）从身边分开。出发点很统一：没有忧虑，所以地方是安全的、结构是牢固的、人是安心的；动词用时，secure 就是让某物进入这种「无忧、确定」的状态，自然发展出保护、固定、取得、确保几条常用义。
### Mnemonic
- type: image
- text: 拉丁语 securus = se-（离）+ cura（忧虑）→ 把忧烦从身边卸下：地方安稳，人心也定。

### Semantic Chain
忧烦 -> 卸下忧烦 -> 安稳牢靠 -> 安全

### Reviewer Notes
- 仓内词条对 *securus = se- + cura* 给出了稳定路线，但本轮仍未联网逐字复核 Etymonline 条目。
- 动词“取得/确保”保留为“让结果变得确定”的后起延伸，不拆成无关义项。
- No aliases.
- confidence: uncertain

## see

### Identity
- lemma: see
- title: see
- pos: v/n
- ipa: /siː/
- cefr: A1
- aliases: saw, seen

### Short Definition
看见；理解；经历；会见；认为；主教教区

### Core Definitions
1. 用眼睛看见或注意到
   - en: to perceive or notice with the eyes
   - priority: 1
   - tags: A
2. 理解、明白或把某事看作某种样子
   - en: to understand, realize, or regard something in a certain way
   - priority: 2
   - tags: B
3. 经历、目睹、会见或负责照看处理
   - en: to experience, witness, meet, or attend to something
   - priority: 3
   - tags: B
4. 主教教区或主教席位
   - en: the seat or diocese of a bishop
   - priority: 4
   - tags: B

### Prototype
see = 窗帘拉开，外面的山全露了出来

### Morphology
- prefix: none
- root: see- / Old English *seon*, Proto-Germanic *sekhwan* (see, perceive)
- suffix: none
- family: see, saw, seen, sight, foresee

### Etymology Narrative

仓内词条把主要动词 *see* 追到 古英语 *seon*，并指出它在古英语里就已经同时覆盖“看见、理解、经历、访问、检查”等功能。英语后来基本保留了这张语义地图，所以视觉感知很自然地扩展成心理理解、人生见证、会见他人以及 *see to it* 一类“负责确保”的表达。只有名词 *see* “主教教区/主教席位”属于另一条历史线，应与视觉动词分开看待。
### Mnemonic
- type: image
- text: 先是眼睛在看 → 英语也拿它讲心里的事：一句 I see，说的就是“我懂了”。

### Semantic Chain
用目而视 -> 留心察觉 -> 心中了然 -> 看见

### Reviewer Notes
- 动词主线按仓内词条保留在 Germanic *seon* 系列；名词 *see* “主教教区”是另一起源，不能并入视觉链。
- 仓内词条提到更深的 Indo-European 对应关系，但本轮未做在线逐项确认。
- `saw` 与 `seen` 是检索友好的屈折形式，不构成自指 alias。
- confidence: uncertain
