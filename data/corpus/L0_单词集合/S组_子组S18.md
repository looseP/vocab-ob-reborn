## suit

### Identity
- lemma: suit
- title: suit
- pos: v/n
- ipa: /suːt/
- cefr: B1
- aliases: suits, suits, suited, suiting

### Short Definition
适合；相配；套装；诉讼

### Core Definitions
1. 对某人、某场合或某种需要来说合适
   - en: to be right or appropriate for someone, something, or a purpose
   - priority: 1
   - tags: A
2. 一套彼此配套的衣服，尤指西装
   - en: a set of clothes made to be worn together, especially a business outfit
   - priority: 2
   - tags: C
3. 法律上的诉讼或民事追诉
   - en: a legal action or proceeding in a court
   - priority: 3
   - tags: C

### Prototype
suit = 上衣和裤子的料子一样；这个时辰对他合适

### Morphology
- prefix: none
- root: suit-/sequ-/secut- / Old French *suite* < Latin *sequi*, *secutus* (follow)
- suffix: none
- family: sue, suit, suitable, suitor, lawsuit

### Etymology Narrative

放回「跟随」（follow）这条家族线上看：经盎格鲁-法语 suit／siwete、古法语 suite／sieute 进入英语，底下连着通俗拉丁语 *sequita 与拉丁语 sequi／secutus（跟随）。几个现代义项由此统一：一组彼此配套、一起跟着出现的衣服叫 a suit（一套衣服）；一件安排若与你的需要贴合，就是 suit you（适合你）；法律义则保留「追着某人走进程序」的旧分支，所以 lawsuit 里的 suit 不是「西装」，而是诉讼、追诉。
### Mnemonic
- type: image
- text: 溯至“跟随”这条线：几件衣裳配成一整套 → 彼此跟得上、配得拢；追着人上公堂，也是这一支。

### Semantic Chain
相随 -> 彼此相称 -> 投合其需 -> 合适

### Reviewer Notes
- 现成仓内 `suit.md`、`lawsuit.md`、`suite.md` 与 `P组_子组D.md` 都支持 `sequi / secutus / suite` 这一“跟随”主线，本轮可稳定沿用。
- 生产稿明确把“套装 / 适合 / 诉讼”统一到 follow / fitting / pursuit 的历史骨架，不把法律义误写成与衣服义完全无关的同形偶遇。
- aliases 保持 none；`lawsuit` 是复合词，`suitable`、`suitor` 是 family，不当作别名。

## superb

### Identity
- lemma: superb
- title: superb
- pos: adj
- ipa: /suːˈpɜːrb/
- cefr: C1
- aliases: 

### Short Definition
极好的；卓越的；壮丽的

### Core Definitions
1. 质量、表现或状态极好的
   - en: excellent in quality, performance, or condition
   - priority: 1
   - tags: A
2. 建筑、景象或场面壮丽华美的
   - en: magnificent or splendid in appearance
   - priority: 2
   - tags: C

### Prototype
superb = 那件瓷器的釉色，整柜子里都挑不出第二件

### Morphology
- prefix: none
- root: superb- / Latin *superbus* (grand, splendid; proud)
- suffix: none
- family: super, superior, superb, superbly, superiority

### Etymology Narrative

源自拉丁语 superbus，整体进入英语。1540年代的抓手是「高贵的、壮丽的」，底层拉丁语 superbus 同时带有「宏伟的、灿烂的」与「骄傲的、傲慢的」色彩；进入现代英语后，稳定保留下来的中心是「出众、极好、壮丽」，口语里常见的 very fine（极好）用法是后来的自然扩展。现代高频义的重点不是「傲慢」，而是「高出一般水准的卓越感」。
### Mnemonic
- type: image
- text: 拉丁语 superbus 一身兼着“宏伟”与“骄傲”两色 → 气度撑得开、压过寻常一头的那种好。

### Semantic Chain
超乎寻常 -> 气度宏阔 -> 品质绝佳 -> 极好

### Reviewer Notes
- 仓内旧稿把 `superb` 机械拆成 `super + -b`，但这一拆法对 L1 生产不够稳；本稿改为保留 Latin *superbus* 整体作为 root，更安全。
- 与 `superior`、`superiority` 同属 super 家族，但现代义焦点不同：`superb` 更偏“极好/壮丽”，不主打等级关系。
- aliases 保持 none；`superbly` 等只进 family，不自指、不造伪别名。
- confidence: source-backed

## superfluous

### Identity
- lemma: superfluous
- title: superfluous
- pos: adj
- ipa: /suːˈpɜːrfluəs/
- cefr: C2
- aliases: 

### Short Definition
多余的；过剩的；非必要的

### Core Definitions
1. 超出需要或正常范围的
   - en: exceeding what is needed or normal
   - priority: 1
   - tags: A
2. 因为并非必需而可以省去的
   - en: unnecessary because it adds no essential value
   - priority: 2
   - tags: C

### Prototype
superfluous = 水漫过缸沿，淌了一地

### Morphology
- prefix: super- (over, beyond)
- root: flu-/flux- / Latin *fluere* (flow)
- suffix: -ous
- family: superfluous, superfluity, fluent, fluid, influence

### Etymology Narrative

经拉丁语 superfluus 进入英语，其字面画面就是「溢出的、漫出来的」，底下连着 superfluere（溢出）——即 super（在上、超出）＋ fluere（流）。这个词适合用「溢出」统筹：当信息、步骤、装饰或物品超出真正需要的边界，就不只是多余（extra），而是多到了可以删去的程度，故称 superfluous。较早英语里还有 superflue 这样的旧形，现代中心义已稳定收束到「多余、非必要」。
### Mnemonic
- type: image
- text: superfluere = super（超出）+ fluere（流）→ 杯子已经满了，还往外漫出来的那一部分。

### Semantic Chain
漫溢 -> 越过限度 -> 超出需要 -> 多余

### Reviewer Notes
- 仓内 `superfluous.md` 的 “上方 + 流动 -> 溢出 -> 多余” 教学骨架是对的，但旧稿把它写得过于像现代英语自由拼装；生产稿改为明确锚定 Latin *superfluere / superfluus*。
- 与 `fluent`、`fluid`、`influence` 同属 flow 家族时，只保留“flow”这一安全共核，不硬讲所有中间历史节点。
- aliases 保持 none；`superfluity` 是派生名词，只列 family。
- confidence: source-backed

## superior

### Identity
- lemma: superior
- title: superior
- pos: adj/n
- ipa: /suːˈpɪriər/
- cefr: B2
- aliases: superiors

### Short Definition
更好的；优越的；上级；长官

### Core Definitions
1. 在质量、能力或价值上更好的
   - en: better in quality, ability, or value than something else
   - priority: 1
   - tags: A
2. 在地位、职级或位置上更高的
   - en: higher in rank, status, or position
   - priority: 2
   - tags: C
3. 上级；主管、长官
   - en: a person of higher rank or authority
   - priority: 3
   - tags: B

### Prototype
superior = 两件摆在一起，这件明显高出一头

### Morphology
- prefix: super- (above, over)
- root: superus / Latin *superus* (situated above, upper)
- suffix: -ior
- family: super, superior, superiority

### Etymology Narrative

直接连到拉丁语 superiorem（原形 superior），它本来就是 superus（在上方的、较高的）的比较级形式。现代英语的几个核心义项没有分家：位置更高是最直观的空间义；等级或地位更高把「上面」转成社会等级；优于他者把「更高」进一步转成品质比较。superior to 与 one's superior 虽一个偏比较、一个偏职级，本质上都共享「更高／在上」这条母线。
### Mnemonic
- type: image
- text: 拉丁语 superus（在上方的）的比较级 → 位置在上头；挪到人身上，就成了位次更高、强过旁人。

### Semantic Chain
居上 -> 位处更高 -> 高人一等 -> 更好

### Reviewer Notes
- 现成 `superior.md` 的“在上方”原型可以保留，但旧稿把它写成纯现代前后缀教学时略显扁平；本稿补回 Latin comparative 背景。
- `superior` 的名词义不是独立新词，而是“更高者/上级”从形容词比较义自然名词化。
- aliases 保持 none；`superiority` 是派生名词，列 family 不列别名。
- confidence: source-backed

## superiority

### Identity
- lemma: superiority
- title: superiority
- pos: n
- ipa: /suːpɪriˈɒrəti/
- cefr: C1
- aliases: superiorities

### Short Definition
优越性；优势；优越感

### Core Definitions
1. 在质量、能力、数量或地位上的优势
   - en: the condition of being better, stronger, or greater than something else
   - priority: 1
   - tags: A
2. 显得高人一等的态度或感觉
   - en: a feeling or manner of being above others
   - priority: 2
   - tags: C
3. 较早或较正式语境中的“更高地位”状态
   - en: the state of being higher in rank, status, or degree
   - priority: 3
   - tags: C

### Prototype
superiority = 比到最后一个回合，他始终压着对手一肩

### Morphology
- prefix: none
- root: superior / Latin *superior* (higher)
- suffix: -ity
- family: super, superior, superiority

### Etymology Narrative

按 superior ＋ -ity 来讲最清楚。Etymonline 给出的路线是15世纪晚期的 superiorite，来自形容词 superior 加名词后缀 -ity，或经古法语／中世纪拉丁语支持，但不管走哪条近路，核心都是「更高的状态」。之后它从「地位或等级更高的状态」扩展到「占上风、占优势」，再到现代常见的优越感（a sense of superiority）这种心理姿态。它不只是抽象的「优越性」，而是「高于别人」的状态被名词化后的系统展开。
### Mnemonic
- type: image
- text: superior（居上）+ -ity → 高过旁人的那种态势：论强弱、论多少、论位次都占着先。

### Semantic Chain
处上 -> 居高之势 -> 占先之优 -> 优势

### Reviewer Notes
- 仓内旧稿主线基本正确，但生产稿把 immediate formation 收紧为 `superior + -ity`，不再反复把内部 `super- + -ior` 当成本词当前层级的主拆分。
- “优势”与“优越感”不是无关义项，而是同一个“高于别人”状态分别落到客观比较与主观姿态上的展开。
- aliases 保持 none；不把 `superior` 写进 aliases，自身也不自指。
- confidence: source-backed
