# S组 · 子组S1（L1 生产词条）

## save
### Identity
- lemma: save
- title: save
- pos: v/prep/conj
- ipa: /seɪv/
- cefr: A2
- aliases: saving

### Short Definition
保存；救助；除了

### Core Definitions
1. 保存；留存
   - en: to keep something for future use
   - priority: 1
   - tags: A
2. 救助；使免于危险
   - en: to rescue someone or something from harm
   - priority: 2
   - tags: B
3. 除了
   - en: except for; with the exception of
   - priority: 3
   - tags: B

### Prototype
save = 火起时他冲进去，把老人背了出来

### Morphology
- prefix: none
- root: salv- / Latin *salvus* through Old French *sauf* (safe)
- suffix: none
- family: save, saver, saving, savings, salvage

### Etymology Narrative

动词约13世纪初出现，源自古法语 sauf、sauver，出自拉丁语 salvare（使安全），而 salvare 又出自 salvus（安全的、无恙的）。画面是把人从险境中拉出来、使之安然无恙。“保存、保留”一义由“使之安全”发展而来；救援与宗教上的“救赎”都保留着这一核心意象。介词“除……之外”一义，则由“把某物另行取出、排除在外”发展而成。
### Mnemonic
- type: image
- text: salvus（平安的）→ 把人从险里拉出来，把东西好好收着，都是叫它不丢、不坏。

### Semantic Chain
安稳 -> 护其周全 -> 留备后用 -> 保存

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/save；early 13c. < Old French *sauf/sauver* < Latin *salvare* < *salvus*.
- Preservation, rescue, and deliverance are related extensions; the exception use is kept as a grammatical branch.
- `saving` is a regular derived/inflected form and is listed as an alias for lookup convenience.
- confidence: source-backed

## scenery
### Identity
- lemma: scenery
- title: scenery
- pos: n
- ipa: /ˈsiːnəri/
- cefr: B1
- aliases: scenic

### Short Definition
风景；舞台布景

### Core Definitions
1. 自然风景
   - en: the natural features of a landscape viewed as a whole
   - priority: 1
   - tags: A
2. 舞台布景
   - en: painted or constructed background used in a theatrical production
   - priority: 2
   - tags: B

### Prototype
scenery = 为观看者构成一个场景的整体视觉背景，既可以是真实景观，也可以是舞台上的布景。

### Morphology
- prefix: none
- root: scen- / Latin *scaena* from Greek *skēnē* (stage, scene)
- suffix: none
- family: scene, scenery, scenic, scenario, scenography

### Etymology Narrative

本次审校中，scenery 一词的检索结果返回的是 scene 条，而非稳定独立的 scenery 段落。该条可支持二者共享的 scen- / scaena / skēnē 背景，以及“由舞台布景转为可见景物”的语义框架；画面是舞台上搭起的景片，后指举目所见的山水风光。但据此无法确定 scenery 一词的独立起始年代，故本条标注为不确定。
### Mnemonic
- type: image
- text: 与 scene 同族，溯至希腊语 skēnē（戏台的帐幕）→ 戏台上搭起的布景，后来也指推窗望见的山水。

### Semantic Chain
戏台帐幕 -> 场上布景 -> 眼前山水 -> 风景

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/scenery；the retrieved response returned the *scene* entry, tracing *scena* < Latin *scaena* < Greek *skēnē*.
- Stage decoration and natural landscape are retained as plausible sense branches, but the dedicated *scenery* evidence is incomplete.
- `scenic` is a related adjective for lookup; it is not treated as a self-reference.
- confidence: uncertain
