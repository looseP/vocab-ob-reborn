## incidence

### Identity
- lemma: incidence
- title: incidence
- pos: n
- ipa: /ˈɪnsɪdəns/
- cefr: C1
- aliases: incidences, incident, incidental

### Short Definition
发生率；发生；影响范围

### Core Definitions
1. 发生率；发生频率
   - en: the rate or number of times something occurs
   - priority: 1
   - tags: A
2. 影响范围；影响
   - en: the effect or bearing of one thing on another
   - priority: 2
   - tags: B

### Prototype
incidence = 这个村子一年里查出三例，隔壁县一例也没有

### Morphology
- prefix: in- (on, upon; historical Latin element)
- root: cadere / cid- (Latin “fall”; inherited stem)
- suffix: -ence (Latin/French abstract-noun layer)
- family: incident, incidental, coincide, decide

### Etymology Narrative

源自拉丁语 incidentia（落在上面、发生），出自动词 incidere（落在……上、发生），由 in-（在……上）加 cadere（落下）构成。画面是雨点落在屋顶上。物理上“落在上面”的意象，转为事件的发生，再转为统计上的发生率，以及对某物所生的影响。
### Mnemonic
- type: image
- text: 雨点一颗颗“落到”统计表上：落下的是 an incident，数它的频率就是 incidence。

### Semantic Chain
落在身上 -> 发生了 -> 出现的次数 -> 发生之率 -> 发生率；发生频率

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/incidence；精确形式为 Latin *incidentia* < *incidere* < *in-* + *cadere*。
- `-cid-` 是 *cadere* 的继承词干，不是现代英语自由词根；统计义与影响义并行保留。
- confidence: source-backed

## include

### Identity
- lemma: include
- title: include
- pos: v
- ipa: /ɪnˈkluːd/
- cefr: B1
- aliases: includes, included, including, inclusion

### Short Definition
包括；包含；列入

### Core Definitions
1. 包括；包含
   - en: to contain something as a part
   - priority: 1
   - tags: A
2. 列入；使参加
   - en: to make someone or something part of a group or activity
   - priority: 2
   - tags: B

### Prototype
include = 名单上写着二十个人，他的名字排在第九

### Morphology
- prefix: in- (in, into)
- root: claudere / clud- (Latin “shut, close”; inherited stem)
- suffix: none
- family: exclude, conclude, preclude, enclosure

### Etymology Narrative

经古法语 encloure 溯自拉丁语 includere（关在里面、围住），由 in-（在内）加 claudere（关闭）构成。画面是把东西圈进围栏里。物理上的围入，扩大为含有某个部分，再转为接纳某人或某物加入一个群体。
### Mnemonic
- type: image
- text: 把名字关进名单的框里：被放在里面就是 include；把它关到外面则是 exclude。

### Semantic Chain
关在里面 -> 围而包住 -> 作为一部 -> 收进群里 -> 包括；包含

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/include；精确形式为 Old French *encloure* < Latin *includere* < *in-* + *claudere*。
- `-clude` 不是现代英语后缀；它是 *claudere* 的历史继承词干，不能按 include 的现代拼写现场拆解。
- confidence: source-backed

### Mnemonic

### Prototype

### Mnemonic
- type: image
- text: 温度计一格一格往上爬；不是突然变多，而是 increasingly 明显地增加。

### Semantic Chain
往上长 -> 越长越大 -> 不断增多 -> 越来越多 -> 日益；越来越

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/increasingly；词源入口为 increase：精确形式为 Old French *encreistre* < Latin *increscere* < *in-* + *crescere*。
- `-ingly` 是现代副词层；词源核心在 increase，不把 increasingly 当作独立拉丁借词。
- confidence: source-backed

## incredible

### Identity
- lemma: incredible
- title: incredible
- pos: adj
- ipa: /ɪnˈkredəbəl/
- cefr: B2
- aliases: incredibly, incredibility, incredulous

### Short Definition
难以置信的；不可思议的；极好的

### Core Definitions
1. 难以置信的
   - en: too extraordinary to be believed
   - priority: 1
   - tags: A
2. 不可思议的；惊人的
   - en: extremely surprising or impressive
   - priority: 2
   - tags: B

### Prototype
incredible = 一个说法超出听者愿意相信的范围；惊人程度后来可不再表示字面上的“不可信”。

### Morphology
- prefix: in- (not)
- root: credere / cred- (Latin “believe”; inherited stem)
- suffix: -ible (adjectival possibility layer)
- family: credible, credit, creed, incredulity

### Etymology Narrative

源自拉丁语 incredibilis（不可置信的），由 in-（不）加 credibilis（可信的）构成，而 credibilis 出自动词 credere（相信）。画面是把心交托出去——本词即其否定。由字面上“不可相信的”，发展为“非凡的、惊人的”，口语中又转为强烈的赞叹。
### Mnemonic
- type: story
- text: 听到一个大得不敢相信的故事：in + credible，先是“不可相信”，再变成“惊人”。

### Semantic Chain
相信 -> 可信 -> 不可信 -> 异乎寻常 -> 难以置信的

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/incredible；精确形式为 Latin *incredibilis* < *in-* + *credibilis* < *credere*。
- 现代口语“棒极了”是从“惊人/难信”扩展来的语用分支，不覆盖核心否定义。
- confidence: source-backed

### Short Definition

### Core Definitions
1. 确实；的确
   - en: really; used to emphasize that something is true
   - priority: 1
   - tags: A
2. 事实上；甚至
   - en: in fact, often strengthening a statement
   - priority: 2
   - tags: C

### Prototype
indeed = 他说会来，人也真的来了

### Morphology
- prefix: in (in, within; phrase element)
- root: deed (act, fact)
- suffix: none
- family: deed, do, indeed

### Etymology Narrative

本词是中古英语的一个短语 in dede，意为“事实上、实际上”，字面即“在行为之中”。画面是嘴上说的不算、要看实际做出来的事。该短语由指涉一个实际的行为，转为确认真实性的话语副词，后来亦用作强调的应答或加强语气的词。
### Mnemonic
- type: contrast
- text: 不是只说，是真正在 deed 中发生：in deed -> indeed，表示“确实”。

### Semantic Chain
在一桩事里 -> 实情如此 -> 真个不假 -> 重重确认 -> 确实；的确

### Reviewer Notes
- Etymonline: https://www.etymonline.com/word/indeed；精确形式为 Middle English *in dede*，字面为 “in deed”。
- 这是短语凝固，不应把 in 当作现代前缀、deed 当作词根再套英语派生规则。
- `indeedness` 仅为避免 aliases 自身 lemma 的占位性派生，非本词常用核心义。
- confidence: source-backed
