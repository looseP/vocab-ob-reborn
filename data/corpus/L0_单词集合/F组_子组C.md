# F组·子组C：L1词源复核

## forecast
### Identity
- lemma: forecast
- title: forecast
- pos: v/n
- ipa: /ˈfɔːrkæst/
- cefr: B2
- aliases: forecaster, forecasting, weather-cast
### Short Definition
预报；预测；对未来走向的估计
### Core Definitions
1. 预测将发生的事
   - en: predict a future event or course
   - priority: 1
   - tags: A
2. 预报天气或其他未来状态
   - en: predict weather or another future condition
   - priority: 2
   - tags: B
3. 对未来结果的估计
   - en: an estimate of a future course or result
   - priority: 3
   - tags: B
### Prototype
forecast = 站在现在，把预先掌握的迹象向前投射，给出未来的图景。
### Morphology
- prefix: fore- (before, in advance)
- root: cast / casten (throw; contrive, plan)
- suffix: none
- family: forecaster, forecasting, weather-cast
### Etymology Narrative

动词约14世纪末作 forecasten，意为“谋划、筹算”，由 fore-“先、前”加 casten（筹划、设计、准备）构成。画面是“把想法先扔到前面去”。“预言事件”一义始见于15世纪末；cast 作“察觉、注意到”讲亦始于14世纪末。名词约15世纪初指“先见、审慎”，大概由动词转来；“对未来走势的推测估计”始于1670年代。底层的 cast 出自斯堪的纳维亚语源，与古 Norse 语 kasta（投掷）相近，其本源不明。
### Mnemonic
- type: image
- text: 先把判断向前投出去，再看它是否命中未来，这就是 forecast。
### Semantic Chain
事前筹谋 -> 先有思虑 -> 向前推演 -> 料定事变 -> 预测将发生的事

### Reviewer Notes
- Etymonline URL: https://www.etymonline.com/word/forecast；精确形式：late 14c. forecast(v.); late 15c. predictive sense; early 15c. forecast(n.); 1670s estimate sense。
- `fore- + cast` 是页面直接给出的构形；cast 的更深来源为 Scandinavian akin to Old Norse *kasta*，页面标为 uncertain。
- 深审：与 predict/prognosis 语义并行但不同源；weather-cast 是后来的平行复合，不把 weather 当本词词源。
- confidence: source-backed

## form
### Identity
- lemma: form
- title: form
- pos: n/v
- ipa: /fɔːrm/
- cefr: A2
- aliases: formed, forming, formula
### Short Definition
形状；形式；构成；形成
### Core Definitions
1. 事物的外形或轮廓
   - en: the shape, appearance, or outline of something
   - priority: 1
   - tags: A
2. 做事的方式或安排
   - en: a way, manner, or established arrangement
   - priority: 2
   - tags: C
3. 表格或待填写的文件
   - en: a document with blanks to be filled in
   - priority: 3
   - tags: C
4. 形成、塑造
   - en: create or give shape or structure to
   - priority: 4
   - tags: B
### Prototype
form = 一个可辨认的轮廓或模板，使材料、行动或观念获得可识别的结构。
### Morphology
- prefix: none
- root: forma (Latin “form, shape, outline, model”)
- suffix: none (整体经 Old French 借入；不按现代拼写强拆)
- family: formal, format, formulate, formula, conform, deform, formation
### Etymology Narrative

名词约1200年作 forme、fourme，意为“外观、形象、相似”，源自古法语 forme（外形、样子、方式），溯至拉丁语 forma（形状、轮廓、外形、模型）。画面是把材料塑出个样子来。forma 本身来源不明；有一种说法经伊特鲁里亚语把它与希腊语 morphē 相系，但并不确定。动词约1300年作 formen、fourmen，出自古法语 fourmer，并直接源自拉丁语 formare（塑造、制作、建造）。
### Mnemonic
- type: image
- text: 先有轮廓和模板，东西才有可辨认的 form。
### Semantic Chain
形状轮廓 -> 外貌模型 -> 样式排布 -> 模板文书 -> 事物的外形或轮廓

### Reviewer Notes
- Etymonline URL: https://www.etymonline.com/word/form；精确形式：c. 1200 *forme, fourme*; c. 1300 *formen, fourmen*; Old French *forme, fourme, fourmer*; Latin *forma, formare*。
- `forma` 的更深词源在页面明确为 unknown；Greek *morphē* 经 Etruscan 的联系只是一种 theory，标 uncertain。
- 深审：form/formal/format/formulate 共享 Latin *forma/formare* 词族；formula 是 “small form”，但不是把英语 form 的末尾强拆成 suffix。
- confidence: source-backed

### Morphology
- prefix: none
- root: forma (Latin “form, figure, shape”)

- family: form, formality, formalize, formally, informal
### Etymology Narrative

约14世纪末已见，意为“与形式或排列有关的”，哲学、神学上指“关乎一物之形式或本质”。源自古法语 formal、formel（13世纪），并直接出自拉丁语 formalis，由 forma（形状、外形）派生。“合乎规定形式、依循公认程式”一义始于15世纪初；名词用法约1600年，而指正式舞会的名词用法1906年见于美国大学用语。
### Mnemonic
- type: image
- text: 形式框架被遵守，场合就从 ordinary 变成 formal。
### Semantic Chain
形与排布 -> 关乎形式 -> 合乎定式 -> 公认规程 -> 遵照公认形式或程序的

### Reviewer Notes
- Etymonline URL: https://www.etymonline.com/word/formal；精确形式：late 14c. *formal*; Old French *formal, formel* (13c.); Latin *formalis* < *forma*。
- `-al` 只标作拉丁形容词层，不把现代英语形式当作现场派生规则；form 的更深来源仍 unknown/uncertain。
- 深审：formal 与 form 词源相连；informal 是带 in- 的反向派生，formal dance 是后起名词用法。
- confidence: source-backed

## format
### Identity
- lemma: format
- title: format
- pos: n/v
- ipa: /ˈfɔːrmæt/
- cefr: B2
- aliases: formatted, formatting
### Short Definition
格式；版式；按格式编排
### Core Definitions
1. 书籍或内容的形状、尺寸和版式
   - en: the shape, size, and layout of a book or work
   - priority: 1
   - tags: A
2. 信息或文件的组织规格
   - en: an arrangement or specification for information
   - priority: 2
   - tags: C
3. 按某种规格整理
   - en: arrange data or material into a specified format
   - priority: 3
   - tags: C
### Prototype
format = 字号、行距、页边都按同一个规矩排

### Morphology
- prefix: none
- root: formatus / formare (Modern Latin “formed”; Latin “to form”)
- suffix: none (借入法语/现代拉丁语整体，不按现代拼写强拆)
- family: form, formatted, formatting, formula
### Etymology Narrative

名词始见于1840年，指书籍的“开本、形状与大小”，经法语 format（18世纪）最终源自近代拉丁语 liber formatus（成形的书），指书籍被做成某种形状与尺寸，出自 formare（塑造）的过去分词，而 formare 又由 forma（形状、样式）派生。计算机上的引申义始于1955年。动词“安排成某种格式”始于1964年，专用于电子计算，由名词转来。
### Mnemonic
- type: image
- text: 内容不变，换进不同版式和数据盒子，就是换 format。
### Semantic Chain
形状模样 -> 成形的书 -> 开本版式 -> 信息规范 -> 书籍或内容的形状、尺寸和版式

### Reviewer Notes
- Etymonline URL: https://www.etymonline.com/word/format；精确形式：1840 *format* (noun); French *format* (18c.); Modern Latin *liber formatus*; 1964 verb; computing extension 1955。
- 本词是经法语、现代拉丁语路径进入英语的整体借词；不把 `format` 按现代拼写拆成 `form + -at`。
- 深审：与 form/formal/formulate 同属 *forma/formare* 词族；现代 verb 是 noun-to-verb conversion，不是古典拉丁构形。
- confidence: source-backed

- cefr: C1

### Short Definition
可怕的；令人望而生畏的；强大难对付的
### Core Definitions
1. 引起恐惧的
   - en: causing fear or dread
   - priority: 1

   - en: so strong, large, or difficult as to discourage effort

### Morphology
- prefix: none
- root: formid- (Latin formido “fear, terror, dread”)
- suffix: -able (Latin formidabilis adjectival layer)
- family: formidably, formidable, redoubtable
### Etymology Narrative

约15世纪中叶出现，意为“引起恐惧的”。源自古法语 formidable（15世纪），出自拉丁语 formidabilis（令人恐惧的、可怕的），来自动词 formidare（惧怕）、formido（恐惧、惊骇、战栗）。画面是让人望而生畏、不敢上前。后来语义转弱，指“力量或规模大到令人望而却步”。注意本词并非由 form（形状）派生，拼写相近只是形似，极易误判。
### Mnemonic
- type: image
- text: 面对一个让人害怕到不敢轻易挑战的对象，记住 formidable。
### Semantic Chain
惧意惊骇 -> 令人害怕 -> 凶悍可怖 -> 凭大凭强挫人劲 -> 引起恐惧的

### Reviewer Notes
- Etymonline URL: https://www.etymonline.com/word/formidable；精确形式：mid-15c. *formidable*; Old French *formidable* (15c.); Latin *formidabilis, formidare, formido*。
- 深审裁决：formidable 与 form/formal/format 仅为近形，不列同源；redoubtable 是语义近邻而非本词派生。
- `-able` 标作拉丁形容词层；不把现代英语 `formid-` 解释为 form + 某个英语词根。
- confidence: source-backed

## formulate
### Identity
- lemma: formulate
- title: formulate
- pos: v
- ipa: /ˈfɔːrmjəleɪt/
- cefr: B2
- aliases: formulation, reformulate, formulary
### Short Definition
用公式表达；系统地拟定
### Core Definitions
1. 用公式或精确措辞表达
   - en: express in a formula or precise form
   - priority: 1
   - tags: A
2. 系统地制定计划、观点或方案
   - en: devise or state systematically
   - priority: 2
   - tags: B
### Prototype
formulate = 把模糊的想法压缩成可重复、可检验的公式或明确方案。
### Morphology
- prefix: none
- root: formula (Latin “small form; rule, method”)
- suffix: -ate (English verb-forming layer)
- family: formulation, reformulate, formula, formulary
### Etymology Narrative

1837年出现，意为“用公式表达”，由 formula 加 -ate 构成。它后来压倒了 form(u)lize（1842年）与 formularize（1845年）两个竞争者。formula 一条给出：该词1630年代作“典礼或仪式中所用的话”讲，源自拉丁语 formula（形式、草案、契约、规章），字面为“小的形式”，是 forma（形式）的指小词。
### Mnemonic
- type: image
- text: 把大而散的想法压成一个小 form，成为 formula，再 formulate。
### Semantic Chain
取个形 -> 定下小规 -> 列成公式 -> 精确措辞 -> 用公式或精确措辞表达

### Reviewer Notes
- Etymonline URL: https://www.etymonline.com/word/formulate；精确形式：1837 *formulate*; *formula* (1630s); Latin *formula* “small form”。
- `-ate` 是页面直接给出的构词层；formula 的 `-ula` 是拉丁 diminutive 层，不能把现代 formulate 的拼写重新切成任意英语词根。
- 深审：formulate 与 format 都回到 *forma/formare*，但 formulate 的英语词源事件是 formula + -ate；formulize/formularize 是未胜出的并行造词。
- confidence: source-backed
