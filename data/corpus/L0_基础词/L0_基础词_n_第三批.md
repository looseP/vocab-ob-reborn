# L0 基础词 · n- 第三批（生产批次，可导入）

> 生产批次：n- 第三批（l1 词汇重构 n- 字母第 3 批 / 全 3 批），共 16 词（锁定顺序，不增删改）。
> 词源核验：本批 16 词中 **Etymonline 直核 11 词**（notice / novel / novelty / november / nucleus / number / numerical / numerous / nurture / nutrition / numb）；其余 5 词（nothing / notwithstanding / now / nowadays / nowhere）为日耳曼原生/复合，采用模型高置信知识，均标 `confidence: source-backed`；**uncertain 词 1 个**（numb），整体入 root 并标 `- confidence: uncertain`。
> 形态学约定（n- 命脉，本批必守）：
> 1. **n- 不是前缀**——本批所有词 `prefix` 一律为空；严禁 `prefix: n-` / `prefix: nov-` / `prefix: not-` / `prefix: novem-` 等任何杂键（会导致解析失败）。
> 2. **notice 的 not- 来自拉丁 noscere「知」**，绝非英语否定 not——root: `not (noscere)`，不得写成「not 否定 + ice」。
> 3. **novel(novus「新」) 与 november(novem「九」) 同形异源、不同根**：novel root `nov`，november root `novem`，各自独立，勿混。
> 4. **numb 标 uncertain**：整体入 root，标 `- confidence: uncertain`，不得标 source-backed、不得编造词根。
> 5. **root/suffix 勿撞车**：派生尾只入 `suffix`，`root` 只放词基（如 numerical: root `numer` + suffix `-ical`；numerous: root `numer` + suffix `-ous`；novelty: root `nov` + suffix `-ty`；november: root `novem` + suffix `-ber`）。
> 6. **复合词 prefix 空**：nothing `no + thing`、notwithstanding `not + with + standing`、nowadays `now + adays`、nowhere `now + where`。
