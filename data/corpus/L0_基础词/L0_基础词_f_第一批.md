## fable

### Identity
- lemma: fable
- title: fable
- pos: n
- ipa: /ˈfeɪbl/
- cefr: B2
- aliases: fables, fabled, fabling

### Short Definition
寓言；神话；虚构的故事

### Core Definitions
1. 寓言
   - en: a short story, typically with animals, conveying a moral
   - priority: 1
   - tags: A
2. 神话；传说
   - en: a legend or myth
   - priority: 2
   - tags: B
3. 谎言；虚构之事
   - en: a lie or invented story
   - priority: 3
   - tags: C

### Prototype
fable = 被说出来的故事（"讲出来的话"）

### Morphology
- prefix:
- root: fab- (L fabula "story, that which is told" ← fari "to speak, tell")
- suffix:
- family: fabled, fabulist, fabulous, fame, fate

### Etymology Narrative
 源自古法语 fable，出自拉丁语 fabula（故事、传说），字面义即“被讲述的东西”，源自 fari（说），原始印欧语 *bha-（讲、说）。画面是口头讲出来的东西——为教诲或为哄骗而讲的故事。 

### Mnemonic
- type: root
- text: fab = 拉丁语“说”(fari) → 炉边讲的那只狐狸，替大人们说了实话

### Semantic Chain
口中所说 -> 传讲的故事 -> 短小的故事 -> 寓言；虚构之事

### Reviewer Notes
- Keep.
- 同源 *bha- 词族（fable/fame）与 faith（*bheidh- "trust"）不同源，勿混。
- confidence: source-backed

## fact

### Identity
- lemma: fact
- title: fact
- pos: n
- ipa: /fækt/
- cefr: A2
- aliases: facts

### Short Definition
事实；真相

### Core Definitions
1. 事实，真实发生的事
   - en: a thing known to be true; what has really occurred
   - priority: 1
   - tags: A
2. 实情，实际情况
   - en: the real state of things
   - priority: 2
   - tags: C

### Prototype
fact = 被做出来的事（"已成之事"）

### Morphology
- prefix:
- root: fact- (L factum "a thing done" ← facere "to do, make")
- suffix:
- family: factor, factory, factual, feat, feasible, manufacture

### Etymology Narrative
 1530年代义为“已做成之事、行为”，源自拉丁语 factum（事件、行为），字面即“被做出来的东西”，是 factus（facere“做”的过去分词）的中性名词用法。语义演变：做成之事→实际发生过的事→1630年代起指“确知为真的事实”。与 feat、manufacture 同源。 

### Mnemonic
- type: root
- text: fact = 拉丁 factum "被做出来的事"（facere 做）；事实就是"已发生/做成的事"。与 feat(功绩)、factory(工厂)、manufacture(制造) 同源（都出自 facere "做"）。

### Semantic Chain
做出来的事 -> 已然发生 -> 确有其事 -> 事实、实情

### Reviewer Notes
- Keep.
- 陷阱：fact 与 feat/factory/feasible/fax 同出拉丁 facere（PIE *dhe-），非 *bha-；勿与 fable/fame（*bha-）混淆。
- confidence: source-backed

- type: root
- text: factory = factor(制造者，facere 做) + -ory(场所) = 制造者之所 = 工厂。与 fact、manufacture 同源于 facere。

### Semantic Chain
做东西的人 -> 做工的场所 -> 成排的厂房 -> 工厂、制造厂

## faith

### Identity
- lemma: faith
- title: faith
- pos: n
- ipa: /feɪθ/
- cefr: B1
- aliases: faiths

### Short Definition
信仰；信任；信心

### Core Definitions
1. 信任，信心
   - en: trust or confidence in a person or thing
   - priority: 1
   - tags: A
2. 信仰
   - en: strong belief in a religion or doctrine
   - priority: 2
   - tags: B
3. 忠诚，忠实
   - en: loyalty, fidelity
   - priority: 3
   - tags: C

### Prototype
faith = 船已经看不见了，他还每天傍晚到码头等

### Morphology
- prefix:
- root: fid- (L fides "trust, faith" ← fidere "to trust")
- suffix: -th (native English abstract-noun suffix, as in truth/health)
- family: faithful, faithless, fidelity, confident, diffident

### Etymology Narrative
 13世纪中期源自盎格鲁-法语／古法语 feid／foi，出自拉丁语 fides（信任、信义、信心），源于 fidere（信任）的词根（原始印欧语 *bheidh-“信任、托付、说服”）。英语词形被改造成了本土 -th 抽象名词的样子，与 truth、health 一路，故看着像本土词，其实是借词。 

### Mnemonic
- type: root
- text: fid = 拉丁"信任"(fides/fidere)；faith 就是"信"。同源 confident(自信的)、fidelity(忠实)。注意与 fable/fame（*bha- "说"）不同源。

### Semantic Chain
信托于人 -> 深信不疑 -> 心中所信 -> 信任、信念

### Reviewer Notes
- Keep.
- 陷阱：faith 来自 fid-/fidere（*bheidh-），与 fable/fame（*bha-）不同根，勿并。
- confidence: source-backed

### Mnemonic
- type: contrast
- text: farther（far 的比较级）专指**物理距离**更远（How much farther?）；further（forth 的比较级）更常指程度"进一步"。两者都为日耳曼原生，prefix 空、root 整体，勿当拉丁前缀。

### Semantic Chain
路远 -> 再远一些 -> 更远一程 -> 更远的；进一步

### Reviewer Notes
