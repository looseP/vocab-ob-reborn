# L0 基础词 · o- 第三批（生产批次，可导入）

> 生产批次：o- 第三批，共 13 词（锁定顺序，3/3 批）。
> 形态学约定：**o- 不是前缀**（本批除 out-/over- 两类真前缀外，oval/overt/owing/own/owner 的 prefix 均为空）。真前缀仅 `out-`（outing/outskirts）与 `over-`（overflow/overhaul/overhead/overhear/overthrow/overtime）共 6 词；其余 7 词 prefix 空。**overt≠over-**（来自 OF *overt* = L *aperire*「打开」，prefix 空，root = apert）；oval 的 ov- 是 ovum 词根首字母（prefix 空）。root 只放词基、suffix 只放派生尾，**零 root/suffix 撞车**。Morphology 段严格四键（prefix/root/suffix/family），无杂键。
> 词源核验：本批 Etymonline 直核 9 词（outing / oval / overflow / overhaul / overhead / overhear / overthrow / overtime / overt，均为 Etymonline 可查的日耳曼复合或拉丁/法语借词）；outskirts 为 out- + skirt 复合（skirt 义「边缘」模型高置信）、owing/own/owner 为 OE 日耳曼原生（与 āgan/āgen 同族，模型高置信）。**全部 13 词标 `confidence: source-backed`，无 uncertain 词**。

### Core Definitions

   - en: a short trip taken for pleasure, especially with a group
   - priority: 1
   - tags: A
2. （体育比赛中的）出场
   - en: an appearance in a match or game
   - priority: 2
   - tags: B

### Prototype

### Morphology

- suffix: -ing

### Etymology Narrative
 14世纪晚期义为“外出、出发的行为”，是动词 out 的动词性名词；现代义“游玩、远足”起于1821年。故字面即“出去这一行为”，后收窄为休闲的出游。 

### Mnemonic

- type: root
- text: out（出去）+ -ing（名词化）→ 周末拎着野餐垫，一家人往城郊的湖边走

### Semantic Chain
往外走 -> 出门一趟 -> 结伴游玩 -> 远足、短途出游

### Reviewer Notes

- Keep.
