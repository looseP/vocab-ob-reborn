# L0 基础词 · p- 第 5 批（生产批次，可导入）

> 生产批次：p- 第 5 批，共 20 词（锁定顺序，5/5 批）。
> 形态学约定：p- 本身**不是前缀**。本批真前缀——**pre-**（×5：preclude / predominant / pregnant / pretext / prevalent）与 **pro-**（×6：proficiency / prone / propagate / prosper / prosperous / province）→ 基形只写进 `prefix:` 字段，绝不另立杂键。其余 9 词（prayer / pride / probability / probable / pug / punish / pure / push / put）prefix 一律为空。pride 是 proud 派生，非 pre-/pro- 前缀；probable/probability 的 prob- = L *probare*「test/approve」整词根（prefix 空），**≠** proficiency 的 pro-+fic（与 proficient/profit 同系），二者 family 互不列。uncertain 词（pug / push / put）整体入 root、标 `confidence: uncertain`，未编造词根。`root` 只放词基、`suffix` 只放派生尾，**root/suffix 零撞车**。Morphology 段严格四键（prefix/root/suffix/family），无杂键（绝不出现 `p-:`/`pre-:`/`pro-:`/`pr-:` 等）。
> 词源核验：本批 Etymonline 直核 12 词（prayer / preclude / predominant / pregnant / pretext / prevalent / pride / probability / probable / proficiency / prone / propagate / prosper / prosperous / province / punish / pure，均为拉丁/罗曼借词或派生词，可溯源）；pug / push / put 为 uncertain（词源不明，标 uncertain）。全部 20 词核对结论见 source-audit。

## prayer

### Identity
- lemma: prayer
- title: prayer
- pos: n
- ipa: /preə/
- cefr: A2
- aliases: prayers, prayerful

### Short Definition
祈祷；祈祷文；恳求

### Core Definitions
1. 祈祷；祷告的行为
   - en: the act of praying to God or a deity
   - priority: 1
   - tags: A
2. 祈祷文；祷词
   - en: a fixed form of words used in praying
   - priority: 2
   - tags: B
3. 恳求；祈望
   - en: an earnest request or hope
   - priority: 3
   - tags: B

### Prototype
prayer = 天没亮他就跪在垫子上，两手合着，念了很久

### Morphology
- prefix:
- root: prec (L precari "pray/entreat")
- suffix: -er
- family: pray, prayerful

### Etymology Narrative
 出自古法语 preiere（祈祷、恳求），源自中世纪拉丁语 precaria，出自拉丁语 precari（请求、乞求、祈祷）。prayer 即由 pray 加表施事或结果的后缀 -er 构成的名词；画面是一番恳切的祈求，或口头诵出，或笔之于书。 

### Mnemonic
- type: root
- text: prec = 请求（precari 祈祷/恳求）→ 清晨跪在长凳前，把那几句话念了一遍又一遍

### Semantic Chain
恳切祈求 -> 默念心愿 -> 对天诉说 -> 祈祷；恳求

### Reviewer Notes
- Keep.
- prayer 非 pre- 前缀：prec- 是拉丁词根首字母，prefix 空；root `prec (precari)` + suffix `-er`，无撞车。与第 4 批 pray 同根。Etymonline 直核。
