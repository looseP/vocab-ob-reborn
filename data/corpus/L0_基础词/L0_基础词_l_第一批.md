> - Etymonline 直核词数：10（lapse / latitude / latent / lecture / large / laser / lad / lash / lazy / ledge）。其余 10 词（lady / lake / last / late / lately / later / laugh / layman / leaf / leave）为 OE 日耳曼原生/复合，采用模型高置信知识，标 `confidence: source-backed`；lad / lash / lazy / ledge 起源不明，标 `confidence: uncertain`。
> - 形态学约定（l- 专属）：英语中 **l- 本身不是前缀**。所有词 `prefix` 必空（复合词 layman/lady 的 prefix 也空，root 标复合）。拉丁整词根（lapse=*labi*→`laps`、latent=*latere*→`latent`、latitude=*latus*→`lat`、lecture=*legere*→`lect`）的 l- 均为**词根首字母**，严禁 `l-:`/`lat-:`/`lab-:`/`lect-:` 之类杂键。Morphology 段严格四键：`prefix:`/`root:`/`suffix:`/`family:`，值可空，无杂键。
> - ⚠️ 命脉排雷：① **lapse ≠ l- + apse** → root `laps (labi)`。② **latent / latitude 与 late 无关**：latitude=*latus*「宽」、latent=*latere*「躺藏」、late=OE *læt*，三者互不相干，不要混源、不要写 `prefix: lat-`。③ **laser** 是现代首字母缩略（1960），prefix 空，整体 `laser`。④ **lecture**=*lectura*←*legere*「读」→ root `lect (legere)`，不是 l- 前缀。⑤ **layman**=lay+man；**lady**=OE *hlæfdige*「揉面包者」=*hlaf*+*dige*。⑥ **last** 是日耳曼（OE *læt*），不是 L *lassus*「疲倦」；与 last「鞋楦」同形异源。⑦ 不确定词（lad/lash/lazy/ledge）整体入 root，标 `confidence: uncertain`，绝不可标 source-backed。
