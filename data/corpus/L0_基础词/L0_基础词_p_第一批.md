# L0 基础词 · p- 第一批（生产批次，可导入）

> 生产批次：p- 第一批，共 20 词（锁定顺序，1/5 批）。
> 词源核验：本批 **Etymonline 直核 13 词**——paint / painful / pact / pair / pale / parachute / parade / paradigm / paradox / parcel / pardon / parent / pass（均为拉丁/希腊/法语借词，已逐词联网核对 head 词源与真前缀）；passage / past 由 pass 派生同源，不再单独直核。pack / package 为日耳曼原生整体借入、pant 为拟声原生，采用模型高置信（与 Etymonline 通用结论一致）；paddle 词源不明，整词入 root，标 `confidence: uncertain`，未编造词根。详见 source-audit。
> 形态学约定（p- 命脉）：**p- 本身不是前缀**。本批真前缀仅 `parachute / paradigm / paradox` = `para-`（希腊）、`pardon` = `per-`（拉丁），共 4 词；其余 16 词 prefix 一律为空。全 p- 字母仅 `pre-/pro-/per-/post-/para-` 五类真前缀（共 27 词），post- 仅限 post/postage/poster/postman/postpone。**posture ≠ post-**（来自 L positura/ponere）。**paint = picture 同根 pict-，但 paint ≠ pain**（pain = L *poena*「惩罚」）。**patriotic(父)/path-(路)/pathetic(感)/patience(忍)/pat(原生) 五系分流**，本批仅涉 paint/pain 分流、pat 系落第 2 批。**pollute ≠ police**。**root/suffix 勿撞车**（派生尾只入 suffix，root 只放词基：painful `pain`+`-ful`、package `pack`+`-age`、passage `pass`+`-age`、parcel `parc`+`-el`、parade `par`+`-ade`）。**family 假同源防范**（paint↔picture 可列、pain↔painful 互列、paint/pain 互不列；pact↔peace/compact 可列；parade/parent/pardon 三词 root 各异不互列）。Morphology 段严格四键（prefix/root/suffix/family），无杂键（绝不出现 `p-:`/`pa-:`/`par-:`/`pat-:`/`pe-:`/`pen-:`/`per-:`/`ph-:`/`pi-:`/`pl-:`/`po-:`/`pol-:`/`por-:`/`pos-:`/`pr-:`/`pro-:`/`pu-:` 等）。

## pack

### Identity
- lemma: pack
- title: pack
- pos: n/v
- ipa: /pæk/
- cefr: A2
- aliases: packs, packed, packing, packet

### Short Definition
包，包裹；背包；打包，塞满

### Core Definitions
1. 包，包裹；背包
   - en: a container or wrapping in which things are bundled; a backpack
   - priority: 1
   - tags: A
2. 打包，装箱
   - en: to put things together into a container or bundle
   - priority: 2
   - tags: B
3. 挤满，塞满
   - en: to fill or crowd tightly
   - priority: 3
   - tags: C

### Prototype
pack = 他把衣裳卷成卷，一件件塞进帆布袋，最后压上盖子

### Morphology
- prefix:
- root: pack (native "bundle", from MDu/MLG pak)
- suffix:
- family: package, packet, unpack, packing

### Etymology Narrative
 出自中古荷兰语／中古低地德语 pak（捆、包，14世纪初），是日耳曼语中对捆扎在一起之物的称呼；英语的派生词 package 与 packet 皆为后来本土构成。注意与拉丁语 pactum（契约）无关，尽管拼写相近。 

### Mnemonic
- type: image
- text: pack 就是"打包"——旅行前把衣服塞进包里 = pack your bags。a pack of wolves（一群狼）像包裹一样聚成一团。注意 pack 和 pact（条约）只是形近，词源不同。

### Semantic Chain
捆成一束 -> 紧紧塞满 -> 收拾齐整 -> 包裹；挤满

### Reviewer Notes
- Keep.
- 日耳曼原生词，prefix 空，整词 pack 入 root；与 pact 仅形似不同源，未误拆 `p-:` 杂键。模型高置信。
- confidence: source-backed

## parachute

### Identity
- lemma: parachute
- title: parachute
- pos: n/v
- ipa: /ˈpærəʃuːt/
- cefr: B1
- aliases: parachutes, parachuted, parachuting

### Short Definition
降落伞；跳伞；空投；安全网（比喻）

### Core Definitions
1. 降落伞
   - en: a device that slows a fall through the air
   - priority: 1
   - tags: A
2. 跳伞；空投
   - en: to drop or descend by parachute
   - priority: 2
   - tags: B
3. 安全网
   - en: a protective provision (e.g. golden parachute)
   - priority: 3
   - tags: B

### Prototype
parachute = 防备坠落的伞

### Morphology
- prefix: para- (defense against, L < parare)
- root: chut (F chute "fall")
- suffix:
- family: parasol, paratrooper

### Etymology Narrative
 1784年由飞行家 F. 布朗夏尔创制的法语混合词，由 para-（防御，出自拉丁语 parare“挡开、准备”，即 Etymonline 的 para-(2)，非希腊语 para-(1)）＋chute（落下）构成。字面即“防止坠落之物”。故前缀是真正的拉丁 para-(2)，词根为法语“落下”一词。 

### Mnemonic
- type: root
- text: para-（防备，拉丁 parare「挡开」）+ chute（坠落，法语）= 防备坠落的装置 = 降落伞。golden parachute（黄金降落伞）= 高管离职的"经济安全网"。parasol（阳伞）= para- + sol（太阳），同款 para- (2) 拉丁家族。

### Semantic Chain
挡住坠落 -> 撑开一顶伞 -> 徐徐落下 -> 降落伞

### Reviewer Notes
- Keep.
- ⚠️ 深度审查纠偏：原 prefix 标 `para- (against, Gk)` 系错误——Etymonline 直核 parachute 用 para- **(2)**（拉丁 parare「挡开/防备」），非希腊 para- (1)。paradigm/paradox 才用希腊 para- (1)，不受影响。已改 prefix `para- (defense against, L < parare)`；root chut 不变，仍是真前缀结构，family 不变。
- confidence: source-backed
