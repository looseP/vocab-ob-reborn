## machine

### Identity
- lemma: machine
- title: machine
- pos: n
- ipa: /məˈʃiːn/
- cefr: A2
- aliases: machines

### Short Definition
机器；机械装置

### Core Definitions
1. 机器/机械装置
   - en: a device made of moving parts that uses power to do a particular job
   - priority: 1
   - tags: A
2. （喻）机构/政治机器
   - en: an organized group or system that controls or influences something (e.g., a political machine)
   - priority: 2
   - tags: C

### Prototype
machine = 希腊语 mēkhanē「装置/巧计」，能让人"做得到"的器具

### Morphology
- prefix:
- root: mach- / mēkhan- (Greek mēkhanē "device, contrivance")
- suffix:
- family: machinery, mechanic, mechanical, mechanism

### Etymology Narrative
 源自希腊语 mēkhanē（器械、巧计；多里斯方言作 makhana），经拉丁语 machina 与中古法语 machine 入英。该希腊语词传统上与原始印欧语 *magh-“能够、有力”相联，即“使人办得到之物”；也有学者视其为前希腊语底层词。无论哪种读法，它指的都是“能把事情办成的装置”。 

### Mnemonic
- type: root
- text: machine 来自希腊语 mēkhanē「装置、巧计」——想象一台替你干活的"机关"，mach- 就是那个"装置"根。别把首字母 m 当前缀，也别和 magn- "great" 混。

### Semantic Chain
巧设的机关 -> 能动的装置 -> 代人出力 -> 机器、机械

### Reviewer Notes
- Keep.
- 陷阱：m- 不是前缀；mach- 是 root，prefix 空。勿与 magn- "great" 混淆。
- confidence: source-backed
