## name

### Identity
- lemma: name
- title: name
- pos: n
- ipa: /neɪm/
- cefr: A1
- aliases: names, named, naming

### Short Definition
名字；名称；名义

### Core Definitions
1. 名字；名称
   - en: a word or set of words by which a person or thing is known
   - priority: 1
   - tags: A
2. 名义；名声
   - en: the reputation or outward appearance of something
   - priority: 2
   - tags: B

### Prototype
name = 老师点名时喊的那两个字，他应了一声

### Morphology
- prefix:
- root: name (OE nama "name"; PIE *h₁nómn̥)
- suffix:
- family: namely, rename, nickname, nameless

### Etymology Narrative
 出自古英语 nama（名字），源自原始日耳曼语 *namô，出自原始印欧语 *h₁nómn̥（与拉丁语 nomen、希腊语 onoma 同源）。这是日耳曼语固有词；英语词形循日耳曼语一系，而非拉丁语 nomen 那一形。 

### Mnemonic
- type: root
- text: name 是日耳曼原生"名字"（OE nama），和拉丁 nomen 同源但英语走日耳曼形。family：namely / rename / nickname 都是它的英语派生，别列 nominal（那是拉丁形，不同英语形式）。

### Semantic Chain
名号 -> 用来称呼 -> 传在外头 -> 名字；名声

### Reviewer Notes
- Keep.
- 日耳曼原生词，prefix 空；family 列英语派生（namely/rename/nickname），不列 nominal。
- confidence: source-backed

- text: nav（船，navis）+ ag（驱动，agere）+ -tion → 舵轮一转，船头偏过暗礁

### Semantic Chain

### Mnemonic
- type: story
- text: 本来是 an eke-name（一个“额外的”名字）→ 被误拆成 a nick-name → 花名册上没人写本名，外号倒传开了

### Semantic Chain
