## think

### Identity

- lemma: think
- title: think
- pos: v/n
- ipa: /θɪŋk/
- cefr: A1
- aliases: thinks, thought, thinking

### Short Definition

想；思考；认为

### Core Definitions
1. 想；思考
   - en: to use the mind to consider something
   - priority: 1
   - tags: A

2. 认为；以为
   - en: to have a particular opinion or belief
   - priority: 2
   - tags: B

### Prototype

think = 在脑中形成并审视一个想法

### Morphology

- prefix:
- root: think (ME thinken; OE þencan / þyncan)
- suffix:
- family: thought, thinker

### Etymology Narrative
 中古英语 thinken 合流了古英语 þencan（思量、构想）与 þyncan（似乎）这两个同源动词。它与 thank 有历史上的亲缘关系，但所拟的原始印欧语来源尚有争议；thing 另是一词，不可并入这一族。 

### Mnemonic

- type: contrast
- text: think 是脑中“想”，thing 是一个“事物”；只差一个字母，也绝不并族。

### Semantic Chain
心中构想 -> 思量 -> 成见 -> 想、思考

### Reviewer Notes

- Keep.
- 与 thank 的历史关系有来源支持，但终极来源存在争议；thing ≠ think。
- confidence: uncertain

### Core Definitions

   - en: happening at a suitable or useful time
   - priority: 1
   - tags: A

2. 及时地
   - en: at a suitable time
   - priority: 2
   - tags: B

### Prototype

timely = 恰好在需要的时间出现

### Morphology

- prefix:
- root: time
- suffix: -ly
- family: time, timeliness

### Etymology Narrative
 中古英语 timeli 承自古英语晚期 timlic，是由 time＋-ly 构成的透明组合。形容词义“及时、在合宜之时发生”自约1200年有载；此处 -ly 构成形容词，不过也另有副词的用法。 

### Mnemonic

- type: root
- text: time + -ly（具有这种性质）→ 在恰当时间出现的 = timely。

### Semantic Chain
时 -> 合时 -> 不迟 -> 及时的

### Reviewer Notes

### Short Definition

### Core Definitions

   - en: extremely small in size
   - priority: 1
   - tags: A

2. 极少的
   - en: extremely small in amount
   - priority: 2
   - tags: B

### Prototype

tiny = 小到几乎需要放大镜才能看清

### Morphology

- prefix:
- root: tiny (earlier tyne / tin; origin uncertain)
- suffix:
- family: tininess

### Etymology Narrative
 现代 tiny 自1590年代有载，出自更早的 tyne／tin（极小，约1400年），该词来源不明。有人把它与 tine（极短的时间、一瞬，或出自古法语 tantin／tantinet）相联，但仅属提议，不足以据此自信地作现代切分。 

### Mnemonic

- type: image
- text: 放大镜下才看清的一粒小点：tiny = 极小的。

### Semantic Chain
极小 -> 尺寸微 -> 量亦微 -> 极小的

### Reviewer Notes

- Keep.
- 不拆 tin-，不与 tin“锡”或 tine“叉齿”强行并族。

### Short Definition

疲倦的；累的；厌烦的

### Core Definitions
1. 疲倦的；累的
   - en: needing rest because of effort or lack of sleep
   - priority: 1
   - tags: A

2. 厌烦的；厌倦的
   - en: bored or annoyed with something repeated too often
   - priority: 2
   - tags: B

### Prototype

tired = 力气被耗掉，身体或心里都想停下

### Morphology

- prefix:
- root: tire (OE teorian / tiorian)
- suffix: -ed
- family: tire, tiresome

### Etymology Narrative
 15世纪初的 tired（更早作 terede）是 tire 的过去分词形容词，义为“精疲力竭的、困乏的”。tire 承自古英语 teorian／tiorian（衰竭、止息；使或变得疲倦），但因缺乏确凿的日耳曼语同源词，其更深的来源不明。 

### Mnemonic

- type: root
- text: tire（使疲倦）+ -ed（处于结果状态）→ 力气耗尽后的 = tired。

### Semantic Chain
力竭 -> 耗尽力 -> 疲惫 -> 疲倦的

### Reviewer Notes

- Keep.
- 派生 tire + -ed 确定，但 tire 的更早来源 uncertain，二者不可混为同一置信层级。
- confidence: uncertain
