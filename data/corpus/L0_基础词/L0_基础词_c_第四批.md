## commonwealth

### Identity
- lemma: commonwealth
- title: commonwealth
- pos: n
- ipa: /ˈkɒmənwelθ/
- cefr: B1
- aliases: commonwealths

### Short Definition
由公民共同组成的政治共同体；联邦；（英）英联邦

### Core Definitions
1. 由公民共同组成的政治共同体 / 国家（如共和国）
   - en: a political community or state; a republic
   - priority: 1
   - tags: A
2. （the Commonwealth）英联邦；联邦（如澳大利亚联邦）
   - en: the Commonwealth (of Nations); a federation
   - priority: 2
   - tags: B

### Prototype
commonwealth = 把"共同的财富 / 福祉"当作一个共同体根基来治理的国家形态。

### Morphology
- prefix:
- root: common + wealth
- suffix:
- family: common, wealth, commonweal

### Etymology Narrative

合成词：common 源自古法语 comun、拉丁 communis "共同的、公共的"；wealth 源自古英语 wela "福祉、well-being"（wel （好））。两词结合表示"共同的福祉 / 公共利益"。
### Mnemonic
- type: story
- text: common（共同的）+ wealth（财富 / 福祉）→ 国库的门对所有公民敞开

### Semantic Chain
共有 -> 众人共享 -> 公众的福祉 -> 联邦、共同体

### Reviewer Notes
- Keep.
- 注意 commonwealth 是复合词，prefix 留空，root 为 common + wealth，不要误拆出 com-。
- confidence: source-backed

## commute

### Identity
- lemma: commute
- title: commute
- pos: v
- ipa: /kəˈmjuːt/
- cefr: B1
- aliases: commutes, commuted, commuting

### Short Definition
通勤（往返上下班）；减刑；以一物换另一物

### Core Definitions
1. 往返通勤（定时往返住所与工作地）
   - en: travel regularly between home and work
   - priority: 1
   - tags: A
2. 减刑；以…替代（commute a sentence）
   - en: reduce a penalty; substitute one thing for another
   - priority: 2
   - tags: B

### Prototype
commute = 把某物"整体换成另一种"——引申为每天把行程在两地之间换来换去。

### Morphology
- prefix: com-
- root: mut
- suffix:
- family: commutate, commutation, commuter, mutable, mutate

### Etymology Narrative
源自拉丁语 commutare "完全改变、常改变"，由 com-（此处或表加强）+ mutare （改变）构成。1889 年起出现"往返上下班"义，源自 commutation ticket（折扣通勤票，1822）。 

### Mnemonic
- type: root
- text: com-(一起 / 加强) + mut(改变，同 mutate) → 早高峰的车厢，早上进城晚上出城，天天换位

### Semantic Chain
改换 -> 拿这个换那个 -> 换车而行 -> 每日往返、通勤

### Reviewer Notes
- Keep.
- 注意 com- 此处或为加强义而非 "together"，但前缀仍标 com-；mut 为 bound root。
- confidence: source-backed
