# L0 基础词 · n- 第二批（生产批次，可导入）

> 生产批次：n- 第二批（共 3 批中的第 2 批），共 16 词（锁定顺序）。
> 形态学约定（四键 only：prefix/root/suffix/family）：n- 不是前缀；本批仅 **nonsense** 的 `non- (not)` 为真前缀，其余所有词 prefix 一律为空；`not-` 来自拉丁 *noscere*「知」而非英语否定 not（notable/notebook 属此路）；`none` 的 *ne-*、`nonetheless` 融合的 *none+the+less* 均非前缀；`numb/noodle` 起源不明整体入 root（本批实际仅 **noodle** 在词表内，标 `confidence: uncertain`，**numb 不在本批 16 词中**）；root/suffix 勿撞车（派生尾只入 suffix，root 只放词基）。
> 词源核验：Etymonline 直核 7 词（nominal / nonsense / notable / nostalgic / noise / notebook / noon）；其余 9 词（nine / nineteen / ninety / none / nonetheless / noodle / north / northeast / northern）为 OE/PGmc 原生或复合，采用模型高置信知识（nine 的 PIE *newn- 亦经 Etymonline 的 nine 条目佐证）。仅 **noodle** 标 `confidence: uncertain`，其余 15 词 `confidence: source-backed`。

- cefr: A1

### Short Definition
九；数字 9

### Core Definitions
1. 数字九
   - en: the number 9; one more than eight
   - priority: 1
   - tags: A

### Prototype
nine = 日耳曼原生数词「九」

### Morphology
- prefix:
- root: nine (OE nigen; PIE *newn- "nine")
- suffix:
- family: nineteen, ninety, ninth

### Etymology Narrative
 出自古英语 nigen，源自原始日耳曼语 *newun，出自原始印欧语 *newn-（九；亦为拉丁语 novem、希腊语 ennea 之源）。这是日耳曼语的本土数词，并无拉丁语层次。 

### Mnemonic
- type: root
- text: nine 是日耳曼原生「九」，和拉丁 novem、希腊 ennea 同源（都出自 PIE *newn-）。别把首字母 n 当前缀。

### Semantic Chain
数到此处 -> 十缺其一 -> 满掌加四 -> 数字九

### Reviewer Notes
- Keep.
- 陷阱：n- 不是前缀；nine 是原生数词，root 入 nine，prefix 空。
- confidence: source-backed

 1570年代，由 note（名词）＋book（名词）构成。note 出自拉丁语 nota（记号、标记，经古法语 note 而来），传统上认为源出 noscere（知晓）。这是英语本土复合词，由一个拉丁语来源的成分与一个本土成分合成。 

### Mnemonic
- type: root
- text: note（笔记，拉丁 nota）+ book（书）= 记笔记的本子。note 同属 noscere 词族，not- 非英语「不」。
