## air-conditioning

### Identity

- lemma: air-conditioning
- title: air-conditioning
- pos: n
- ipa: /ˈeəkəndɪʃənɪŋ/
- cefr: B1
- aliases: 

### Short Definition

空调；空气调节（系统/设备）

### Core Definitions
1. 空气调节系统
   - en: a system that cools and dries the air in a building or vehicle
   - priority: 1
   - tags: A

2. 受控环境
   - en: a controlled, artificial environment (figurative)
   - priority: 2
   - tags: C

### Prototype

air-conditioning = 给空气加上“条件”（温度/湿度可控）

### Morphology


- prefix:
- root: air + condition (air < Latin *aer* "air"; condition < Latin *condicio* "state, agreement" ← *con-* "together" + *dicere* "to say")
- suffix: -ing (noun-forming)
- family: air, condition, air-conditioner, air-conditioned

### Etymology Narrative
 20世纪初的现代复合词：air（拉丁语 aer“空气”）＋conditioning（出自 condition，拉丁语 condicio“状态、约定”＝con-“共同”＋dicere“说”，即“共同订下的条款”）＋-ing。画面是给一个空间配上被设定好“条件”的空气——温度、湿度都按要求调定。 

### Mnemonic

- type: image
- text: 空调 = 给空气(air)加了条件(condition)：不是随便的空气，是“有条件的”空气（温湿度可控）。

### Semantic Chain
调节空气 -> 控温控湿 -> 室内送风 -> 空气调节系统

### Reviewer Notes



- Modern mechanical coinage, not a classical root word; components are source-backed (Latin *aer* / *condicio*).
- Do not invent a Greek/Latin root for the whole word; it is a 20th-c. compound.
- confidence: source-backed

## algorithm

### Identity

- lemma: algorithm
- title: algorithm
- pos: n
- ipa: /ˈælɡərɪðəm/
- cefr: B1
- aliases: 

### Short Definition

算法；逐步求解的计算步骤

### Core Definitions
1. 计算步骤集
   - en: a set of steps or rules for solving a problem, especially by a computer
   - priority: 1
   - tags: A

### Prototype

algorithm = 按固定步骤算到底的方法

### Morphology


- prefix:
- root: al-Khwarizmi (borrowed Arabic proper name, "native of Khwarazm", a mathematician; via Medieval Latin *algorismus* → French *algorithme*)
- suffix:
- family: algebra, Algol

### Etymology Narrative
 1690年代源自法语 algorithme——此形是受希腊语 arithmos（数）的误联而改造的，本作中世纪拉丁语 algorismus，是阿拉伯语 al-Khwarizmi 的讹变转写，此人乃把高等数学传入西方的数学家之姓氏。画面颇特别：这套方法是以一个人命名的，而非以某个概念命名。 

### Mnemonic

- type: story
- text: 算法 = 波斯数学家 al-Khwarizmi 的名字被误拼成了“algorithm”；一个古人的名字，如今驱动着机器一步步运算

### Semantic Chain
记数方法 -> 逐步演算 -> 定下规矩 -> 计算步骤集

### Reviewer Notes



- The *-th-* spelling is a false link to Greek *arithmos* "number"; the word is actually from a personal name, not from "number".
- Do not present *arithmos* as the root; that is a later folk-etymology.
- confidence: source-backed

   - priority: 1

### Prototype

### Morphology

### Etymology Narrative

提出说法 -> 当庭陈述 -> 暂无实证 -> 声称、指称

### Reviewer Notes



- Hybrid word: form from *ex- + litigare*, sense from *ad- + legare*. L1 should cite the sense source (*ad- + legare*); mention the form layer only if useful.
- Do not treat *litigare* as the semantic root; it explains the spelling, not the meaning.
