## tree

### Identity

- lemma: tree
- title: tree
- pos: n/v
- ipa: /triː/
- cefr: A1
- aliases: trees, treed, treeing

### Short Definition

树；树状结构

### Core Definitions
1. 树
   - en: a tall plant with a woody trunk and branches
   - priority: 1
   - tags: A

2. 树状结构
   - en: a branching diagram or structure
   - priority: 2
   - tags: B

### Prototype

tree = 从坚实树干向外分枝的木本植物

### Morphology

- prefix:
- root: tree (OE treo, treow)
- suffix:
- family: treeless, treelike

### Etymology Narrative
 中古英语 tre 出自古英语 treo／treow（树、木料、木材），源自原始日耳曼语 *trewam 及原始印欧语 *drew-o-（木、树），最终出自 *deru-（坚固、坚实）。同一“坚固”这一深层观念也是 true 与 trust 的底子，但二者并非 tree 的直接形态派生。 

### Mnemonic

- type: image
- text: 一根坚实的树干向上分枝，就是 tree；“坚实”也是它最深层的历史意象。

### Semantic Chain
坚稳 -> 木 -> 活树 -> 树、树木

### Reviewer Notes

- Keep.
- 与 true / trust 仅说明深层 PIE 同源；family 不列二者。
- confidence: source-backed

- type: root
- text: trop = turn（转）+ -ic；太阳到回归线仿佛转身，所以是 tropic。

十二；十二个

### Core Definitions

   - en: the number 12
   - priority: 1

### Prototype

twelve = 十之后再余下两个

### Morphology

- prefix:
- root: twelve (OE twelf; historical PGmc *twa-lif-)
- suffix:
- family: twelfth

### Etymology Narrative
 古英语 twelf 出自原始日耳曼语 *twa-lif-，历史上是“二”与一个意为“留下”的成分复合而成，故为“十之外余下两个”。这是历史上的构词，并非现代的英语切分：词末的 -ve 并非后缀。 

### Mnemonic

- type: story
- text: 古老数法先数满十，再说“还余两个”——two left over ten，就是 twelve。

### Semantic Chain
数至十 -> 余二 -> 十二

## twenty

### Identity

- lemma: twenty
- title: twenty
- pos: num/n/adj
- ipa: /ˈtwenti/
- cefr: A1
- aliases: twenties

### Short Definition

二十；二十个

### Core Definitions
1. 二十；二十个
   - en: the number 20
   - priority: 1
   - tags: A

### Prototype

twenty = 两组十

### Morphology

- prefix:
- root: two (historical OE twegen)
- suffix: -ty (group of ten)
- family: two, twentieth

### Etymology Narrative
 中古英语 twenti 出自古英语 twentig，由 twegen（二）＋-tig（十个一组）构成。历史上那个透明的意义是“两个十”，并在现代 two＋-ty 这一分界中保留下来。 

### Mnemonic

- type: root
- text: two（两）+ -ty（十的组）= 两组十 = twenty。

### Semantic Chain
二 -> 两组十 -> 二十

### Reviewer Notes

- Keep.
- root 为 two 的历史词干，suffix 为 -ty；prefix 必须为空。
- confidence: source-backed

### Core Definitions
1. 两次
   - en: two times or on two occasions
   - priority: 1
   - tags: A

2. 两倍
   - en: two times as much or as many
   - priority: 2
   - tags: B

### Prototype
twice = 这活儿他做过一回，后来又做了一回

### Morphology

- prefix:
- root: twi / two
- suffix: adverbial genitive -s
- family: two

### Etymology Narrative
 中古英语 twies 承自古英语晚期 twiga／twigea（两次）的变体，源自原始日耳曼语 *twiyes 与原始印欧语 *dwis-。它带副词性属格 -s；拼写中的 -ce 只是记录那个清音 /s/，并非后缀。 

### Mnemonic

- type: root
- text: twi / two（两）+ 副词属格 -s = 两次；看到 -ce 只当拼写，不当词缀。

### Semantic Chain
二 -> 两回 -> 双倍量 -> 两次

### Reviewer Notes

- Keep.
- suffix 是 adverbial genitive -s；-ce 仅为拼写结果，绝不标作 -ce 或 -ice。
- confidence: source-backed
