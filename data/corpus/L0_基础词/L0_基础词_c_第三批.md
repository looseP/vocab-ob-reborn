## cloth

### Identity
- lemma: cloth
- title: cloth
- pos: n
- ipa: /klɒθ/
- cefr: A2
- aliases: cloths (plural, rare)

### Short Definition
布，布料（用于制衣或包裹的织物）。

### Core Definitions
1. 织物；布料
   - en: woven fabric used for clothing or covering
   - priority: 1
   - tags: A
2. （特定用途的）布块
   - en: a piece of such fabric for a specific use
   - priority: 2
   - tags: C

### Prototype
cloth = 一块可裁剪、可包裹的扁平纺织物，是衣服的原料。

### Morphology
- prefix:
- root: cloth (OE clāth)
- suffix:
- family: clothes, clothing

### Etymology Narrative

源自古英语 clāth（布、衣物），起源不确定；推测出自原始日耳曼语 *klīthaz。cloth／clothes／clothing 为同一日耳曼词族的同源派生。
### Mnemonic
- type: image
- text: 布店招牌 "CLOTH" 像一块挂着的布料，联想裁缝剪布。

### Semantic Chain
纤维 -> 织成 -> 布料 -> 衣料 -> 成衣

### Reviewer Notes
- Keep.
- 陷阱：cloth 与 clothes（衣服）、clothing（衣物）同源，但 clothes 是复数形式、clothing 是集合名词，不可混用为同一词。
- confidence: uncertain

- pos: n
- ipa: /klaʊd/
- cefr: A1
- aliases: clouds (plural), cloudy (adj)

### Short Definition
云（天空中由水汽凝结成的团块）。

### Core Definitions
1. 云；云朵
   - en: visible mass of vapor in the sky
   - priority: 1
   - tags: A
2. 一团（尘、烟等）
   - en: a mass of dust, smoke, etc.
   - priority: 2
   - tags: C

### Prototype
cloud = 天空中漂浮的、像山岩一样成团的白色水汽聚合体。

### Morphology
- prefix:
- root: cloud (OE clūd)
- suffix:
- family: cloudy, cloudless

### Etymology Narrative

源自古英语 clūd（岩石、山丘），约13世纪中叶因形似岩石而转义为「天空中的水汽团块」。属日耳曼语源。
### Mnemonic
- type: image
- text: 古义"岩石"→山峰状白云，联想 cloud 像天上飘的石头。

### Semantic Chain

### Reviewer Notes
- Keep.
- 陷阱：cloud 与 cloudy 同源（cloudy = cloud + -y）；原义为"岩石"而非"风"或"水"。
