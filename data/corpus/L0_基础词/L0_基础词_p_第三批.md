# L0 基础词 · p- 第三批（生产批次，可导入）

> 生产批次：p- 第三批，共 20 词（锁定顺序，3/5 批）。
> 词源核验：本批 **Etymonline 直核 12 词**——persuasion / picture / pilgrim / plumber / plagiarism / pneumonia / plain / place / planet / plant / plentiful / plateau（均为拉丁/希腊/法语借词，已逐词联网核对 head 词源、真前缀与各词根）。petty（OF petit）、pile（L pila）、pickup（原生复合）、play（OE plegan 原生）为模型高置信（与 Etymonline 通用结论一致）。pig / pinch / pint / pocket 词源不明，整体入 root，标 `confidence: uncertain`，未编造词根。详见 source-audit。
> 形态学约定（p- 命脉）：**p- 本身不是前缀**。本批真前缀仅 `persuasion` = `per-`（拉丁，intensive），共 1 词；其余 19 词 prefix 一律为空。逐词对齐 master §6 第 3 批速查的 prefix/root/confidence。重点陷阱：⚠️ **picture = paint 同根 pict-**（picture root `pict (L pingere "paint")` + suffix `-ure`，prefix 空；family 列 picture/paint/depict；**picture ≠ pain**，pain = L poena 第 2 批，不互列）。⚠️ **pilgrim = peregrinus 整体借入**，prefix 空，root `peregr (L peregrinus "foreigner/wanderer")`；**绝不拆 per- + ager**（Etymonline 虽析 peregrinus < per- + agri，但项目惯例按整体借词处理，避免与 agriculture/agent 假同源）。⚠️ **plumber = plum (L plumbum "lead") + -er**：-um 是拉丁中性尾非 suffix，root `plum`。⚠️ **pneumonia = pneum (Gk pneumon "lung" < pneuma "breath") + -ia**：pn- 不发音是希腊特征非前缀，root `pneum`。⚠️ **plain / planet / plant / plateau 四词不同根**（plain = L planus「flat」；planet = Gk planētēs「wanderer」plan-；plant = L planta「sprout」；plateau = F plat「flat」L plattus < Gk platus），family 互不列。⚠️ **pickup = pick + up 复合**（pick 原生），prefix 空，root `pick + up`。uncertain 词（标 uncertain，整体入 root，不编造）：pig（ME pigge unknown）、pinch（OF pincier uncertain）、pint（OF pinte uncertain）、pocket（poke 指小 uncertain）。plagiarism = plag (L plagiarius < plaga)；place = plac (L platea < Gk plateia)；plentiful = plen (L plenus) + -ful；play = 原生。**root/suffix 零撞车**（派生尾只入 suffix，root 只放词基）；Morphology 段严格四键（prefix/root/suffix/family），无杂键（绝不出现 `p-:`/`pa-:`/`pe-:`/`pen-:`/`per-:`/`ph-:`/`pi-:`/`pl-:`/`po-:`/`pr-:` 等）。

## persuasion

### Identity
- lemma: persuasion
- title: persuasion
- pos: n
- ipa: /pəˈsweɪʒn/
- cefr: C1
- aliases: persuasions

### Short Definition
说服，劝服；说服力；信念，信仰

### Core Definitions
1. 说服，劝服
   - en: the action of persuading someone to do or believe something
   - priority: 1
   - tags: A
2. 说服力
   - en: the power of persuading; the ability to win others over
   - priority: 2
   - tags: B
3. 信念，信仰
   - en: a belief or set of beliefs, esp. religious or political
   - priority: 3
   - tags: B

### Prototype
persuasion = 把人彻底说动的力量/过程

### Morphology
- prefix: per- (intensive, L)
- root: suad (L suadere "urge/advise")
- suffix: -sion
- family: persuade, persuasive

### Etymology Narrative
 出自拉丁语 persuasio（说服、劝说），是 persuadere（说服）的动作名词，由 per-“彻底、强力”＋suadere（劝促、劝告）构成；后者的意象是“使之甘美可受”。故 persuasion 即“彻底把人劝转过来的力量”。14世纪晚期经古法语进入英语。 

### Mnemonic
- type: root
- text: per-（彻底）+ suad（劝，suadere）→ 说了三次，最后那次对方点了头

### Semantic Chain
反复劝说 -> 说动了心 -> 令人信服 -> 说服；信念

### Reviewer Notes
- Keep.
- TRAP 规避：persuasion prefix = **per- (L "thoroughly")** 真前缀，root = `suad (L suadere "urge/advise")`，suffix `-sion`；与 per- 五词同族前缀。Etymonline 直核（拉丁 persuasio ← persuadere = per + suadere）。
- confidence: source-backed
